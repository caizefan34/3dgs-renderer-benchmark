## Root Cause

**Primary:** H5 (Over-allocation)

The `isect_tiles` CUDA kernel pre-allocates intersection buffer capacity based on worst-case scenario:
```python
capacity = N * MAX_INTERSECTIONS_PER_GAUSSIAN  # ~80x over-provisioning
```

NOT based on actual intersection count. This is **capacity allocation**, not **workspace allocation**.

**Secondary:** H2 (Hierarchy Auxiliary Memory) - minor contribution

**NOT:**
- ❌ H1 (Intersection Amplification) - not measured
- ❌ H3 (Temporary Workspace) - only 1.76 GB before OOM
- ❌ H4 (Allocator Fragmentation) - reserved matches allocated

---

## Fix Design

**Strategy:** Chunked Intersection Processing

**Implementation:**
```python
if N > 1_500_000:
    # Process in chunks to reduce peak memory
    chunk_size = 1_500_000
    for chunk in chunks:
        isect_tiles(chunk)  # Smaller allocation per chunk
    # Concatenate results
else:
    isect_tiles(full_N)  # Original path
```

**Expected Impact:**
- Memory reduction: 3-4×
- Speed impact: 5-10% overhead (chunking)
- Correctness: Identical (same algorithm)
