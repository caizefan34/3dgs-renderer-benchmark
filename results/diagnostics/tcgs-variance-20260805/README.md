## Ranking exclusion

This directory is intentionally outside `results/measured/`. The normal
leaderboard loader scans only measured, reproduced, and paper evidence roots.

Pass B changes `warmup_frames` from the canonical protocol value of 30 to
150. Its `metrics.json` files were generated by a diagnostic collector run
that accepted the altered warm-up for summary convenience; they retain the
canonical protocol identity and therefore **must not be ingested as Tier A
records**. The authoritative warm-up value is stored in each
`tcgs/speed/benchmark_results.json` artifact.

Passes A and C also stay diagnostic so that later observations cannot replace
the pre-declared first complete leaderboard batch after outcome inspection.

Rendered PNGs are not committed, matching the repository's existing evidence
policy. Per-view quality metrics and render-output hashes remain in the JSON
artifacts.
