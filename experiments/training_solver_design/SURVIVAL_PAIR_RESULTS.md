# 成对子体的 CUDA 合成与全分辨率出生检查

2026-09-27。本轮实现了隔离 CUDA 原型，并在真实 P11 room@2000 的三个 1920×1080 视角上检查了出生图像和共享参数 VJP。**没有进行训练，没有证明加速、最终画质改善或原创性。** 原型沿用生产投影、SH、父体 tile 覆盖及排序；它不是已可替换训练器的完整表示生命周期。

## 生产渲染器确实会破坏简单因式分解

审查的 P11 gsplat `Common.h` 使用 `MAX_ALPHA=0.99`、`ALPHA_THRESHOLD=1/255`、`TRANSMITTANCE_THRESHOLD=1e-4`。原生 CUDA 在更新透射率后若达到终止阈值，会**排除当前高斯**。源码和实际 .so 的哈希均保存在结果 JSON。

通过原生 `rasterize_to_pixels` 在像素中心构造独立子体，实测如下。颜色含非黑背景；VJP 同时包含 RGB 与 alpha 输出。

| 条件 | 简单独立子体相对父体的最大 RGB 差 | 整对处理原型的最大 RGB 差 |
|---|---:|---:|
| 父像素 alpha=0.006，子体各低于 1/255 | 0.00465600 | 0 |
| 原始 alpha=0.999，父体被截到 0.99，但子体先用未截断值因式分解 | 0.00698411 | 0 |
| 前缀透射率约 0.001，父体 alpha=0.95，提前终止发生在子体中间 | 0.000597835 | 0 |
| 原始 opacity=1，直接未截断平方根反传 | 非有限梯度 | 有限梯度，与父体一致 |

先截断父体 alpha 可以解决上界问题，但不能解决子体阈值和中途终止。因而当前表示选择把两个子体作为一个合成单元，阈值和提前终止对整对作决定；这不是两个独立标准高斯的生产排序语义。

## 浮点出生守恒需要稳定的整对表达式

首次原型使用 `A=h1+(1-h1)*h2`，其中 `hi=ai/(1+sqrt(1-ai))`。真实全分辨率检查中，256 对出生的图像差通过门槛，但全部 260,530 个高斯成对出生时最大 RGB 差为 **0.00207585**，超过事先规定的 `2e-5`。平均差仅 `1.42e-8`，原 FP32 平均损失差为零，说明不能只看平均损失来声称图像守恒。原失败结果保留在 `room_survival_pair_v2.json`，对应 CUDA 源码为 `survival_pair_cuda_v1.cu`。

最终原型使用同一数学函数的以下表达式：

```text
si = sqrt(1-ai), hi = ai/(1+si)
A = a1 + s1/(s1+s2) * (a2-a1)
B = A*c1 + (A-h1)*(c2-c1)
image += T*B
T *= 1-A
```

`A=1-sqrt((1-a1)(1-a2))`，`B` 是两个相邻子体的预乘颜色。上述写法在 `a1==a2` 时浮点 `A` 直接返回 `a1`，在 `c1==c2` 时浮点 `B` 返回 `A*c1`。因此出生时保持与单体一致的阈值输入及透射率递推，无须放宽图像门槛。对非重合、异色子体，解析 VJP 与独立 FP64 PyTorch 顺序合成参考比较：最大图像绝对差 `5.73e-8`，独立子体梯度最大绝对差 `1.58e-7`、相对 L2 `2.44e-7`。这是小图算子检查，不是移动后全场景训练验证。

## 三个真实全分辨率视角

P11 room@2000，N=260,530，视角 202/188/206。对照原生无编辑两次重放；三种原型配置分别是全部单体、固定 256 个父体成对、全部父体成对。全场景子体从同一个父体张量构造，VJP 沿共有参数链回传至屏幕坐标/conic/RGB/opacity 以及 3D 位置、log-scale、旋转、opacity logit、SH。独立子体的自由度只在前述小图参考中验证。

事先门槛：RGB max-abs ≤2e-5、mean-abs ≤1e-6；各 VJP relative-L2 ≤max(1e-3, 3×原生重放误差)，极小参考范数使用 max-abs ≤1e-8。最终没有调整门槛。

| 视角 | 三种配置相对原生的最大 RGB 差 | alpha 最大差 | 各配置/参数中的最大 VJP relative-L2 |
|---|---:|---:|---:|
| 202 | 2.38419e-7 | 0 | 5.17059e-5 |
| 188 | 2.38419e-7 | 0 | 2.03499e-5 |
| 206 | 2.38419e-7 | 0 | 1.77603e-4 |

9 个配置的图像和 VJP 检查均通过。原生图像重放逐位相同；原型与原生仅为上述容差范围内一致，不能称整条 CUDA 链逐位一致。实际损失差为 0 或 1.49e-8。数据在 `room_survival_pair_v3.json`，完成状态为 true，当前源文件哈希全部匹配。

## 成本与仍未完成的关键项

这个逐像素全局读取/atomic 累加原型主要用于验证公式。包含子体构造、合成、fused loss 和 VJP 的三个采样中位数（毫秒）：

| 视角 | 单体原型 | 256 对子体 | 全部成对 |
|---|---:|---:|---:|
| 202 | 75.65 | 83.22 | 145.89 |
| 188 | 92.22 | 90.46 | 171.63 |
| 206 | 93.82 | 93.25 | 175.42 |

这些是固定顺序的少量诊断计时，未随机交错，未纳入完整训练。全部成对表示本身含两倍内部子体，不能把与未分裂单体的时间比直接解释为相对同点数普通分裂的成本，更不能由 256 对的小幅波动推导加速。需要在同父体、同子体数量下与标准/已发表守恒分裂比较。

下一步必须解决子体移动后的 union tile 覆盖、成组深度排序与真实遮挡的差异，以及如何退出暂态表示。当前复用父体覆盖和排序只能严格支持出生检查。随后才能用保持真实 Adam 历史的 64/512 步局部分支测跨视角收益，并实现可比较成本的优化 kernel。局部通过后再对 FastGS-Big 做正式未见视角、多场景完整训练；目前这些均未完成。

**后续阶段结论**：union tile 覆盖已在固定状态/小位移下实现并核对，但成组排序与物理深度排序在六个全分辨率视角上明显分离，且整对方案未显示跨视角即时质量共同改善。当前配置已退出强优化主线，详见 `SURVIVAL_MOTION_RESULTS.md`；上段保留为出生阶段当时的待办记录。

## 原创性边界进一步收紧

[Revising Densification in Gaussian Splatting](https://arxiv.org/abs/2404.06109) §3.3 已明确给出 `q'=1-sqrt(1-q)` 及有理化式 `q/(1+sqrt(1-q))`。该工作将修正用于 clone 的标量 opacity，明确指出中心以外不能完全消除偏差，split 则维持原 opacity。**平方根恒等式和有理化式均为直接先行工作。** 当前逐像素非高斯核与整对语义只是有待证明价值的表示方案；本轮工程检查不构成原创认证。
