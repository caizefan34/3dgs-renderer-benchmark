# 遮挡条件化的高斯容量交换：研究设计与淘汰门

2026-09-27。**状态：退出原创强方法主线。**原生子体＋邻近删除的真实版本在 room 的质量/成本机会门失败；随后全文核对又发现“多视角误差引导出生＋低贡献高斯迁移＋损失驱动接受”已有直接先行。下文保留可复核的假设与数学，但不能再把宽泛容量交换定位为开创性方案。目标仍是每步作者协议有效全分辨率、原始训练损失和标准 3DGS 输出，以更少完整墙钟获得更高正式未见视角 PSNR/SSIM、更低 LPIPS，并与最新强方法同协议比较。实测见 `FASTGS_CAPACITY_EXCHANGE_SCREEN.md`；不原样重复到 garden。

## 为什么改成“交换”

在 FastGS room@4100，固定原生子体的透射率校正解析拟合可在局部像素降低约 19% 的 MSE，但单子体对整图原损失的平均改善只有 `5.22e-7`；14 个局部正收益子体联合插入后，四张内部检查训练图的平均原损失反而变差 `1.91e-7`。24 个候选的 CPU 六视角拟合净相位为 4.365 秒，不能放进每 100 步的增密事件。详见 `FASTGS_BIRTH_FIT_RESULTS.md`。这否定当前**原生子体＋单点局部MSE＋CPU扫描**组合的机会，不否定更好的几何或真正的容量转移。

新假设不是再增添一批小点，而是把一个遮挡/训练成本高、贡献冗余的旧高斯 `d`，换成一个更准确且未来像素工作量更小的新高斯 `a`。最终点数不增加，若交换后的正式新视角质量更好、每步 GPU 像素交互更少，才同时满足两个目标。这个因果链的每环都需实测。

## 精确的单交换局部模型

对相机 `v`、像素 `p`，从当前物理深度排序中删除 `d`，记真实合成图像为 `I⁻`。把几何已定的 `a` 插到其物理深度，记插入前透射率 `T⁻`、其后景单位入射颜色 `B⁻`、屏幕核 `G_a`、opacity `q`、常量颜色 `c`。只要 tile/alpha 支持和提前终止分支固定，标准 alpha 合成给出

```text
I(d → a) − I⁻ = T⁻ G_a(q c − q B⁻).
```

定义 `u=qc`、`z=(u_R,u_G,u_B,q)`，每个 RGB 像素有三行线性响应 `A_p z`，其中 `A_p=[T⁻G_a I₃, −T⁻G_a B⁻]`。固定几何时可以在多个训练视角求解 `min_z Σ_p w_p ||A_p z − (Y_p−I⁻_p)||²`，约束 `0≤q≤q_max, 0≤u_j≤q`。它是四变量凸代理，**不是**原始 L1+fused-SSIM 的精确最优，也不是完整训练的质量结论。权重、上限和候选几何必须只用训练视角决定，正式测试图绝不可调参。若扩成视角相关 SH，需要重新推导输出颜色约束与成本，不直接套用四变量解。

删除本身在固定支持下也有局部精确式：若旧层前透射率 `T_d`、自身 alpha `a_d`、颜色 `c_d`、其后景 `B_d`，则 `I⁻−I = T_d a_d(B_d−c_d)`。**必须用删除后的 `T⁻,B⁻` 再拟合出生**；沿用删除前缓存会把遮挡变化算错。多个候选相互遮挡时也不能把单点收益相加：前后两个新层 alpha 为 `a,b`、颜色 `c,d`、共同后景 `B` 时，联合图像变化减去两者独立变化为 `−ab(d−B)`。1万次 FP64 随机合成的删除后出生恒等式最大误差 `3.41e−16`、双出生交互式最大误差 `2.28e−16`，但把双出生误当独立相加的 RGB 误差可达 `0.441`。证据：`capacity_exchange_oracle.py/json`。这些仍只是理想合成数学。

## 原型必须实现的五步

1. **候选几何**：从原分辨率训练图像的多视角一致残差和投影深度产生缺失表面的 3D 位置/尺度/法向提案，而非默认复制原生 split 子体；从作者现有剪枝候选中提名可删除的 `d`。三角化、patch matching、多视角残差增密已有先行，不能算贡献。先限定每事件很小的候选池，记录每个提案如何产生。
2. **交换评分**：在作者排序与真实前后景下，拟合出生 `q,c`；对候选 `(d,a)` 计算删除区域与出生区域的并集，加入 SSIM 窗口边界，估计原损失和未来可见高斯—像素交互。零影响的画外视角仍计入整图均值，防止局部百分比虚高。
3. **联合冲突处理**：对共享相机 tile/深度链的候选建立冲突图。先测试互不相交的交换；重叠候选提交前必须按物理深度重排并用作者渲染器检查整批，不能累加单候选代理收益。
4. **训练内成本路径**：复用 FastGS 已有的十视角增密/剪枝评分或普通全分辨率反向中的投影、残差和透射率数据；所有额外投影、后景、矩阵归约、排序、检查和状态迁移都计入事件时间。当前 CPU 扫描 4.365 秒/24 候选远超可接受成本；若不能把候选求解与现有渲染通道融合，就停止。
5. **提交与续训**：正式提交后存活旧点继承原优化器状态，新点按同协议初始化，完整记录 RNG/相机序列。短程比较交换、仅删、仅生、作者原生拓扑和不编辑；原生整图 L1+fused-SSIM、PSNR/SSIM/LPIPS与训练用时都报告。即时损失不能替代 512 步乃至 30K 后的结论。

## 成本与质量硬门

- 第一门：在至少两个开发场景的真实状态，候选交换需在**未参与其拟合的训练视角**上产生有分量的整图原损失收益，且不是由单一相机决定；与等预算随机交换、仅删、仅生、原生增密比较。这里的内部检查不是正式泛化证明。
- 第二门：GPU 原型必须核对作者 CUDA 的 tile 支持、alpha `1/255` 截断、0.99 上限、`1e-4` 提前停止和物理排序；在临界分支使用作者原生重渲染。完整事件额外墙钟应由以后少做的实际 raster/Adam 工作回收，不能用“点数较少”推算。room 的平行输入准备臂与 Faster-GS `main` 仅差约 2.81 秒完整墙钟，且是一次运行；若下游不省时，按144事件粗算，额外成本预算只有约19.5毫秒/事件。这是**压力测试数字**，不是跨方法可比的正式速度门。
- 第三门：同一优化器完整检查点的 64/512 步配对，所有提案/筛选时间计入；若收益只有千分位 dB 或跨视角/种子不稳，直接退出，不启动 30K。不能靠调内部检查视角后再称其独立。
- 最终门：固定规则后在未触碰场景和多种子完整训练，统一有效输入分辨率、图像预处理、GPU、评测、计时边界；逐场景报告完整墙钟、等质量时间、正式未见视角 PSNR/SSIM/LPIPS 与失败例。基线至少包括 FastGS-Big 和可复现的 Faster-GS；TurboGS、ACE-GS、MMGS 等按可用代码与协议另行同条件复现。只有同协议结果和充分查重后才讨论“与最新强方法不相上下”及原创性。

## 先行边界与最大风险

已读原文快照显示：[FastGS](https://arxiv.org/abs/2511.04283)有多视角残差与贡献式剪枝；MVGS、GaussianPro、MVG-Splatting有多视角几何/残差增密；[SteepGS](https://arxiv.org/abs/2505.05587)有分裂曲率；[MMGS](https://arxiv.org/abs/2605.19304)有多视角排序、OT 聚合及矩守恒分裂；[ACE-GS](https://arxiv.org/abs/2606.21244)有动量一致增密、敏感度剪枝及频率补偿。更直接的是，[3DGS-MCMC](https://arxiv.org/abs/2404.09591) §3.4 已把低透明度高斯迁到活高斯位置、调整opacity/scale和优化器状态；[Metropolis-Hastings Sampling for 3D Gaussian Reconstruction](https://arxiv.org/abs/2506.12945) §§4.2–4.3 已按多视角误差产生粗/细出生提案、迁移低贡献高斯，并用近似损失/体素占用决定接受。两者使“把冗余高斯挪到缺失处”及其残差驱动版本**不能作为原创核心**。删除后物理遮挡条件下的解析颜色/opacity拟合与实测像素成本是更窄的可能区别，但当前实测没有有分量的整图收益或工作量节省；没有理由将这点数学区别升级为强方法。原文快照与SHA256见 `topology_sources/sources.json`。这仍非穷尽查重。

最大可能失败点是：可删除的大 footprint 高斯承担真实低频结构，出生小点补不回；多视角残差提案可能追逐反光/曝光/标定误差；单步交换评分未必预测长期优化；精确局部后景及 SSIM 边界的 GPU 成本可能吃掉全部节省；同点数不意味着更少 pixel work。任何一条在开发场景被数据否定，就停止本方案，不用改验收口径。

**首个真实机会门的裁决（D）**：room@4100 以固定的原生子体1467为出生几何，从近邻231个可投影旧点按面积选六个并加入其父体，删除后逐一重新拟合出生颜色/opacity。六拟合视角选出的删除45461使原损失相对不编辑变化+1.24e−9；交换−5.29e−7，仅比只出生−5.22e−7多极微弱改善。四内部检查训练视角的交换−1.20e−7，反而略逊于只出生−1.21e−7。作者原生十视角高斯—tile实例数净少23/7,615,103，即0.000302%，不能代表GPU计时，但明确没有大结构成本机会。**停止这个具体原生子体/单近邻删除版本**，不做续训或garden重放。尚未被检验的是经多视角定位的新生几何及规模化交换；它们不能继承此负结果以外的任何成功主张。
