# Full-resolution adjoint, primitive-wise multirate backward: source gate

Date: 2026-09-28. This is a read-only mechanism audit, not an experiment or speed/quality result.

**Decision: no GPU arm for the proposed simple accepted-hit skipping path.** The proposal retains the full-resolution render, original L1+SSIM scalar loss and its full-image pixel adjoint, then evaluates broad, high-work Gaussian parameter gradients on a sparse spatial grid while narrow Gaussians receive dense gradients. This differs from P17's coarse-image render/loss, but shares P17's projected-footprint-based primitive-wise gradient-rate core. It is also a different estimator from the existing uniform 75% random sparse-adjoint pilot, which did not save CUDA backward work and did not demonstrate a three-metric improvement. No originality or quality gain follows from either distinction.

In the pinned FastGS and SAD-GS bucket backward (`backward.cu:497–601` in the audited sources), each accepted hit updates the per-pixel alpha/transmittance and accumulated color state that later Gaussian gradients need. Continuing past an unsampled broad Gaussian would corrupt the gradients of later narrow Gaussians. A correct sparse-parameter variant must retain that state recurrence and suppress only the chosen Gaussian's derivative accumulation. Therefore the exp/alpha, traversal and state-transfer work remains; accepted-pair fractions are not a valid speed-saving estimate. Any native speed claim must measure the actual removed instructions and complete step/process time.

Broad projected footprint does not ensure smooth full-loss gradients: the pixel adjoint, occlusion/transmittance boundaries and later-color term can vary sharply across its footprint. Deterministic spatial quadrature may be biased; the rasterizer's screen-space `absgrad` densification statistic also needs separate parity/error treatment. The existing `SPATIAL_PREDICTOR_DESIGN.md` spatial-moment/Gauss–Hermite line and published multi-scale/frequency-aware GS methods increase novelty risk.

The smallest pre-GPU gate for a redesigned component would be a CPU counterexample with a wide background Gaussian, narrow foreground occluder and high-frequency adjoint: later narrow-point gradients must remain unchanged while all wide-point parameter and `absgrad` errors are reported. A source-level instruction/cost budget must then show a material saving after retaining the state recurrence. These gates would test only a backward component. No evidence links this component to SAD's measured broad-scale PSNR deficit or to a full quality-and-cost win, so do not start this arm now.
