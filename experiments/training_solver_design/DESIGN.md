# 3DGS 几何—外观联合训练设计

日期：2026-09-26。状态：**研究候选，已有数学检查与真实检查点局部探针；没有端到端加速或 SOTA 证据。**

当前筛选裁决：**本版低秩方向尚未通过 G2，不进入生产 CUDA 或大规模训练。** OGC 的固定几何 SH-PCG 和 Instant Colorization 提供了直接先行工作；结合强对照负结果，关闭以此为主创新的定位。本文保留历史方案，下面“主攻”指原方案。当前候选见 [TOPOLOGY_DESIGN.md](TOPOLOGY_DESIGN.md)，同样尚无完整训练收益证据。

## 1. 目标与当前结论

用户目标是训练更快，同时重建质量更高。当前以新视角图像质量为主；若主张表面重建更准确，另做有几何真值的实验，不以 PSNR 代替几何误差。

主攻算法：**保持完整 photometric 梯度，在有计算预算的局部高斯组内，对少量几何与外观方向联合求解，并通过实际渲染选择它是否优于普通 Adam 更新。**

这比“对所有 SH 做全局精确消元”更具体：不构造全局 Hessian、不缓存全场景逐像素 Jacobian、不假设一次小矩阵求解已经得到全局最优外观。不把“颜色参数占比高”转述为同等比例的加速。

核心研究假设是：部分收敛延迟来自重叠高斯以及几何/外观之间的相互补偿；低维联合更新能够以较小额外成本减少达到目标质量所需的训练迭代。这个假设尚未在完整训练中验证。

第一阶段输出仍为标准 3DGS：位置、尺度、旋转、opacity、SH，不引入额外推理网络或专有渲染表示。训练算法的变化不能伪称原 Adam 语义等价。

## 2. 实际证据如何约束设计

### 2.1 文献边界

本次读取了下列全文 HTML 的方法/补充材料相关段落；带版本 URL、文本摘要和 HTML SHA256 保存在 `literature_evidence.json`。

| 工作 | 已有机制 | 对本设计的约束 |
|---|---|---|
| [3DGS-LM](https://arxiv.org/html/2409.12892v2) | LM、最多 8 次 PCG 内迭代、逐像素/高斯梯度缓存、Jacobian 乘法、线搜索 | “二阶法、缓存、考虑耦合”不是新颖性；必须计入构建与遍历缓存 |
| [LM-RS](https://arxiv.org/html/2504.12905v1) | 无显式矩阵 LM/CG、视图与像素采样、Jacobi 预条件器 | “矩阵自由＋采样”已经存在；不能仅击败未经优化的 LM |
| [TurboGS](https://arxiv.org/html/2606.15924v1) | 稀疏像素、结构损失、局部 Moment-LM；补充材料明确将高阶 SH 留给 Adam，避免增大系统 | 需证明低秩表示能经济地恢复被省略的几何/SH 与邻近高斯耦合 |
| [Faster-GS](https://arxiv.org/html/2602.09999v1) | 高度优化的训练实现、内存访问与反向传播等 | 对照应包含强工程基线，不能把已有 fused-SSIM/fused-Adam 算作贡献 |

FastGS 的多视图增密、Taming 的预算增密也属于已有方法。变量投影、Schur 补、子空间 Newton、分块预条件本身是已有数学。潜在贡献只能是具体方向构造、受限工作集、耦合恢复与实测收益；当前材料不构成首创证明。

### 2.2 数学检查

`appearance_oracle.py` 是小型 FP64 透视 EWA 3DGS，使用深度顺序 alpha 合成与 degree-1 SH；不模拟生产 tile 裁剪或 early-out。8 项测试覆盖：

- 固定几何线性算子与独立 alpha 合成相符；
- 颜色截断改变时，无条件线性假设失败；
- 正则化颜色解的一阶驻点条件；
- 精确内层解下的 envelope 梯度与穿过求解器的梯度及有限差分相符；
- 未收敛的内层解不能冒充精确消元梯度；
- Schur 解与完整耦合线性系统相符；
- 独立高斯求解遗漏真实投影重叠产生的交叉项；
- 若几何图像方向位于颜色方向张成的空间内，无正则消元会抹掉该几何信号。

因此正式候选使用**当前状态的真实梯度＋有限维局部步**，不对粗略颜色解盲目 `detach` 后宣称获得精确 reduced-objective 梯度。

### 2.3 真实检查点局部探针

`real_crop_probe.py` 读取 room / bicycle / garden 的真实 PLY、相机和实拍图像。每场景三个相邻拟合视角、一个训练集内部保留视角，512 宽图像上的 26×26 裁剪，只更新贡献最大的 32 个高斯的 DC 颜色；其余参数固定。图像 SSIM 用有效 11×11 窗口，未测 LPIPS。

相机按名称排序、每八张排除一张，使用约定的 LLFF 划分；没有独立认证官方 split。该 NumPy 渲染器未通过生产 gsplat parity，因此以下只是**机制诊断，不是官方质量指标**。

| 场景 | 拟合裁剪 ΔPSNR | 拟合裁剪 ΔSSIM | 保留裁剪 ΔPSNR | 保留裁剪 ΔSSIM |
|---|---:|---:|---:|---:|
| room | +2.2966 dB | -0.004040 | +0.0486 dB | -0.000227 |
| bicycle | +0.4557 dB | +0.004837 | +0.1647 dB | +0.002097 |
| garden | +0.7800 dB | -0.003384 | +0.0770 dB | -0.000570 |

这些是一次带 ridge 的 MSE 联合颜色步相对于未更新模型的变化。不能称为训练收敛提升，更不能称为对 FastGS 的优势。固定学习率的 100 步缓存 Adam 得到接近目标值，garden 略好于单次活动集合线性解；这也暴露了截断活动集合变化的影响。

CPU 算子构建约数秒至数十秒，局部求解仅数毫秒；后者单看虽然很快，把全部成本算入后无法支持端到端加速。三场景正规矩阵非对角项 Frobenius 范数占比约 0.11–0.41，说明该受限问题确实存在耦合，但该比值不能量化完整训练收益。

**决策：不直接采用 MSE-only 全颜色解。** 保留原结构损失；把完整求解作为正确性/收益上限 oracle，生产候选压缩求解维数，另测摊销成本。

### 2.4 低维联合更新的负结果与约束修正

`subspace_probe.py` 使用 10 个真实透视投影的合成高斯、3 个拟合相机、1 个保留相机，优化其中 8 个高斯的位置与 degree-1 SH。每高斯一个位置方向、DC 和高阶 SH 各一个方向，共 24 维。尺度与 opacity 固定，故不代表完整训练器。

- 第一版 `subspace_evidence.json` 使用固定绝对阻尼和统一缩放：5 个开发种子全部回退到 Adam。
- 第二版 `subspace_scaled_evidence.json` 使用 IRLS 曲率权重与对角尺度阻尼，但仍统一缩放整个方向：耦合步仍全部回退。
- 第三版 `subspace_bounded_evidence.json` 直接求解盒约束 QP，避免无效方向的大系数压缩所有有效方向。精确全损失梯度与方向 Jacobian 的一致性、盒约束 KKT 条件都通过检查；无约束 Schur 与完整解也一致。
- 盒约束联合步在 5 个种子上都优于原学习率的单步 Adam；但**5/5 都没有超过允许 {1,2,4} 倍步长的全体 Adam 对照**。与只放大相同 8 个高斯的匹配对照相比为 3 胜、1 平、1 负，改善尚不足以证明额外计算划算。

这三轮都是开发诊断，不是独立确认。主要结论：必须把学习率/线搜索作为强对照，否则会把更大步长的收益误归因给耦合求解。当前不支持“低秩联合步很强”或 2× 的判断；需要真实早/中/晚训练状态和带历史 Adam 的匹配实验。

## 3. 精确定义的优化目标与参数

初版沿用宿主训练器：

`L = 0.8 * mean(abs(render - GT)) + 0.2 * (1 - SSIM(render, GT))`。

SSIM 窗口、padding、背景、颜色截断、eps2d、投影、相机、SH 升阶、opacity reset、增密窗口全部与对照固定。初版不加入稀疏像素损失、学习型先验或新正则，防止改变多个变量后无法归因。

几何采用局部参数：位置 3、log-scale 3、旋转切空间 3、opacity logit 1；外观为 SH 系数。旋转用指数映射回单位四元数；不直接无约束优化 4 个 quaternion 元素。

每次计算完整原损失的梯度及原 absgrad 增密统计。**允许采样曲率，初版不采样或丢弃一阶梯度。** 曲率是方向尺度的近似，一阶目标仍包含全部当前视图像素的结构信号。

## 4. 方向、分组与小系统

### 4.1 块与方向

- 一个块最多 K=8 个高斯。根据当前视图中的共同像素贡献筛选少数强邻居；三维距离只作候选生成，不能替代屏幕重叠。
- 块划分中每个逻辑高斯 ID 最多归属一个块，避免重复提交更新。跨块耦合暂时忽略，由全体候选的实际损失比较发现有害的联合更新。
- 每个高斯初始使用一个几何方向：宿主 Adam 当前将采取的几何步。
- 每个高斯使用最多两个外观方向：DC 与高阶 SH 的当前更新分量；退化/零范数方向删去。后续可比较梯度/历史步方向，但不能预先添加一串未验证变体。
- 因而每块 q≤24，不是 8×(10+48)=464 维的完整参数系统。
- 方向以图像响应尺度或参数预条件尺度归一化；归一化常数与系数一起保存，不能混淆位置单位和颜色单位。只对当前微批次生成方向，不持久保存全 N×48×rank 的新缓冲。

这限制了搜索空间，不保证覆盖完整 Newton 步。普通 Adam 更新仍在候选空间内或作为独立回退，避免将“低秩”当作无损压缩。

### 4.2 梯度与曲率

记 θ 当前参数，U_b 为块方向，s_b 为其系数：`δθ_b=U_b s_b`。

```text
g_b = U_bᵀ ∇θ L                 # 使用已有完整原目标梯度
J_b = ∂ render / ∂ θ_b * U_b   # 只对选中曲率样本计算
H_b = J_bᵀ W J_b + λ D_b
H_b s_b = -g_b
```

W 必须为非负，D_b 为正定尺度矩阵，λ>0。均匀或有明确正概率的采样必须包含正确的平均/重要性权重。若像素/视图分布不同，记录概率；不能把高误差采样的未加权 Hessian 称为原分布的无偏估计。

SSIM 耦合邻近像素。最小版 H_b 是正定预条件模型，**不是原 L1+D-SSIM 的精确 Hessian**；g_b 仍由真实目标给出，最后由真实损失判定。后续只有测到必要收益才实现完整窗口 Jacobian。结构窗口计算所需 halo 必须完整，不能用填零的未渲染邻域冒充真实 SSIM。

划分几何系数 u 和外观系数 v：

```text
S = Huu - Huv * solve(Hvv, Hvu)
u = solve(S, -gu + Huv * solve(Hvv, gv))
v = solve(Hvv, -gv - Hvu*u)
```

这是对**低维局部模型**的 Schur 消元，不是对全部场景 SH 的精确变量投影。FP32 Cholesky 为首个实现；FP64 oracle 检查解残差与预测下降。出现非有限值、非正定或预测下降≤0即回退，记录失败原因。

步长约束不能靠“解出任意大系数，再统一缩小到最大系数上限”实现。当前 CPU oracle 使用每系数 [-4,4] 的有界 QP；该数只是开发配置。约束激活后，Schur 只能用于给定活动集合的自由变量系统，不能声称无约束 Schur 解加裁剪等价于有界最优解。生产活动集合算法的分支与额外求解成本仍待评估。

## 5. 与 Adam、真实渲染及拓扑的事务顺序

初版每个纠正事件的语义必须明确，不能靠环境开关猜测：

```text
在 θ 上：渲染当前训练批次，计算 L 和完整梯度
在拓扑改动前：读取 absgrad、更新原统计（与基线时序一致）
选择块；保存这些逻辑 ID 的旧参数；构建方向与局部系统
计算普通 Adam 步和联合候选步（使用同一份梯度）
Adam moments 与全局 step 只更新一次
执行普通 Adam 更新，保存选中参数的 Adam 结果
渲染同一批次得到 L_adam
将选中参数替换为 old_selected + coupled_step，其他参数保留 Adam 结果
再次真实渲染得到 L_candidate
若有效、满足步长约束且 L_candidate < L_adam：接受
否则恢复选中参数的 Adam 结果
需要的增密/prune/reset 按冻结时序执行；使受影响块和缓存失效
```

上述模型没有完整表示未选中 Adam 步与所选块之间的交叉项，所以两个真实候选的比较是必要保护。两个额外 forward、损失、复制与回退都计入耗时。初版不能假装验证免费；是否可以复用基线图像要由相机调度和实际数据依赖证明。

接受标准仅保证该当前训练批次不劣于同一步 Adam 候选，不保证全训练集单调，更不保证新视角质量。若使用额外校准视角，它们必须来自训练集内部并计入计算。

对照 Adam 的 survivor moments 不重置。所有 newborn/split/prune 状态规则由宿主协议规定并一致执行；纠正步本身不进行第二次 Adam step。下一步梯度在实际提交的新参数上计算。momentum 不因当前不可见就静默跳过。

## 6. 预算与缓存协议

### 6.1 内存上限

示例工程配置：同时处理 128 块，q≤24，每块最多 m=384 个标量曲率残差：

- J 方向响应：128×384×24×4 B = 4.5 MiB；
- 局部 H：128×24×24×4 B = 288 KiB；
- 当前 1024 个高斯的两个 48 维外观方向：0.375 MiB。

这些只是新增局部工作区，**不包含**原模型、Adam 状态、图像、排序/可见列表、双缓冲与求解器其他临时量。峰值必须测，不许将该数写成总显存。完整场景逐交互缓存按 E×记录字节数计算；在大量重叠场景上很容易超出消费级 GPU 容量。

### 6.2 缓存合法性

只重用同一冻结线性化点内的算子。键至少包含相机/投影、参数版本、拓扑版本、SH degree、renderer 配置和颜色活动集合。更新几何/opacity、深度次序、裁剪/early-out、截断状态或拓扑后失效。当前选中的块不能跨视图仅凭 ID 相同就重用投影。

每个像素可能接触多个块，因此实际方向响应行数是“像素—块”关系数，可能远大于像素数。固定每块预算和流式处理限制内存，但相应采样误差必须量化。

### 6.3 时间模型与选择门

```text
T_event = 原始完整训练步
          + 分组/方向构造 + 曲率数据生成 + 小系统求解
          + 两次真实 forward/loss + 参数暂存/提交
T_campaign = 所有普通步与纠正事件之和 + 初始化/拓扑/其他协议内成本
```

若候选平均每步贵 α 倍，要达到总训练 2×，达到同质量的步数必须降到基线的 1/(2α) 以下。例如 α=1.5 时需至少约 3× 的有效迭代减少；这是代数条件，不是预测。

纠正频率与覆盖率由预注册先导扫描决定。一次正向 loss 下降不能直接当作多步收益。用配对短窗口的“实际改善/墙钟”校准是否调用求解器；成本无法回收的场景或阶段使用宿主 Adam，不能藏掉回退比例。

## 7. 增密作为第二阶段

第一阶段固定原增密策略，隔离求解器效果。之后才验证：联合更新后仍然存在、在多个训练视角上一致的残差，是否更适合指导新增容量。

候选分裂必须与“不编辑、继续训练”比较，扣除现有参数可修复误差；按未来增量交互成本而非仅 N 评分。对替换父体的 split 必须同时建模父体消失。保持候选集合/新增数量相同的消融可检验评分本身；改变 N 的增益与求解器增益分别报告。

禁止把颜色过拟合造成的低训练残差理解为几何已正确，也不能因为残差大就增加容量去拟合曝光或标定误差。

## 8. 实施门与完整对照

| 门 | 必须验证 | 失败后的动作 |
|---|---|---|
| G0：数学 oracle | 线性/截断、梯度、Schur、有限差分 | 修正公式；不进行速度测试 |
| G1：生产数据与渲染 | 真相机、激活、GT、SSIM、标准后端输出 parity；小规模原目标求解 | 独立 NumPy 结果仅保留诊断标签 |
| G2：方向与模型 | 低秩步比同样预算 Adam/随机方向更好；真实下降与预测相关 | 改方向或淘汰，无需实现大矩阵 |
| G3：成本 | 计入构建、采样、验证、回退后，配对窗口改善/毫秒有优势 | 不扩大 GPU campaign |
| G4：收敛 | 多场景从 SfM 初始化、完整训练，固定质量目标和预算 | 不能用 late-checkpoint 修色代替 |
| G5：确认 | 13 场景×至少3 seeds，独立确认集、固定实现和超参 | 未通过则不宣称强基线优势 |

G0 当前通过 8 项。G1 仅完成真实数据局部独立探针，**生产 parity 未完成**。G2 的三轮合成单步筛选未证明相对强步长对照的优势，故尚未通过；G3–G5 未完成。

必须的消融：宿主 Adam；仅联合 DC；几何/外观独立小步；同维数联合步；仅单高斯块；邻近高斯块；完整颜色 oracle；加入增密评分。保持损失、初始化、相机预算和增密一致，才可归因给耦合恢复。

系统级对照至少包括 current gsplat+fused-SSIM、FastGS、Faster-GS、Speedy-Splat，以及可复现的 3DGS-LM、LM-RS、TurboGS。官方代码不可用的方法标明仅文献对照，不把不同 GPU 的公开秒数混入实测比值。

两张主曲线：达到预注册联合质量目标的时间；相同墙钟下的新视角 PSNR/SSIM/LPIPS。另报 N、峰值显存、失败场景、回退比例、实测算子/求解/验证成本。至少一个预定主质量指标显著改善、其余不劣，才写“质量更高”。

挑战目标：相对强基线 time-to-quality ≥2×且同预算质量改善。先导进入确认的建议门为 ≥1.3×；两个数字都是目标，不是本次结果。PSNR -0.1dB / SSIM -0.003 / LPIPS +0.005 可作为预注册不劣边界，不能当“更高”的证明。

## 9. 当前交付与未解决问题

已交付可执行 oracle、8 项测试、三个真实检查点的局部探针、全文文献证据、受限维数算法与明确的状态/成本/验证协议。

关键未解问题：完整梯度之后增加纠正事件，是否能省回足够迭代；低秩方向是否覆盖真正有价值的耦合；曲率样本能否预测原结构损失下降；生产求解时局部像素—块关系是否成为新瓶颈；跨视图/跨场景泛化是否改善。不能把这些待验证条件写成已经成立的优势。

下一步执行顺序见 `NEXT.md`。完整目标保持为更快训练与更高重建质量，不能以数学测试或局部修色成功替代。
