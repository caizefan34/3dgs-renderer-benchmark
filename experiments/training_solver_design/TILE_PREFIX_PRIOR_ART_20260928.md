# Joint foreground transmittance certificate: adjacent prior art

Date: 2026-09-28. Source/official-project-page boundary only; originality remains unproven.

- [gsplat AccuTile PR #927](https://github.com/nerfstudio-project/gsplat/pull/927) and local `reports/accutile/accutile-identity-audit.md` already give conservative opacity-aware ellipse/tile support and a faster strip/SnugBox enumerator. A single Gaussian's zero-contribution tile rejection is occupied; the current proposal instead asks whether the **joint foreground** can certify that a whole tile has reached the native early-stop threshold before sorting deeper entries.
- The pinned [RoofGS](https://arxiv.org/abs/2608.15785) §IV-A includes duplication-front-end culling and compressed depth keys. The local current reading does not establish its use of a tile-wide alpha-lower-bound product or a pre-sort certified depth cutoff. The older `@intersection_sorting_research_gap_audit.md` statement that RoofGS uses a coarse depth map for occlusion was unsupported; both copies of that historical audit now carry a warning.
- [OccluGaussian](https://github.com/OccluGaussian/OccluGaussian.github.io) (ICCV 2025) says its occlusion-aware component clusters cameras into scene regions and culls Gaussians invisible to a region for large-scene rendering. Its official project-page abstract does not describe this per-tile transmittance certificate.
- [Proxy-GS](https://github.com/Visionary-Laboratory/Proxy-GS) (CVPR 2026) provides an occlusion prior via a **mesh depth cache** rendered before training, per its official README. That is different input and geometry from a certificate derived only from the current Gaussian alpha bounds. The README alone does not exhaust its paper/implementation; a full check remains required before any originality claim.

The frozen offline gate is `TILE_PREFIX_TRANSMITTANCE_GATE_20260928.md`. Even if it passes, this would be an exact-culling *systems* component. It would still need measured native complete-training wall time, unchanged full-resolution loss/gradients, multi-scene/multi-seed formal three-metric noninferiority, and a complete prior-art audit to satisfy the user's method goal. Do not describe a positive entry count as saved backward accepted-pixel work: native early termination already avoids those contributions.
