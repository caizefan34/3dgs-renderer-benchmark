# 逐像素透射率连续的高斯分裂：表示级研究假设

2026-09-27。目标是全分辨率训练时，以更少修复步骤/更有效的点数增长达到更好的正式新视角质量，并在同协议下接近或超过 FastGS-Big 等强基线。隔离 CUDA 成对合成原型已通过 room 三个全分辨率视角的出生检查；后续六视角小位移检查揭示固定父深度排序的结构性差异及 A/B 权衡，当前配置**不再作为强优化主线**。没有训练速度或最终质量提升，更没有已证原创/SOTA。两阶段结果见 `SURVIVAL_PAIR_RESULTS.md` 与 `SURVIVAL_MOTION_RESULTS.md`。

## 为什么不是再换一个剪枝分数

本项目 room@10K 的 80 点删除 oracle 发现 A 视角一阶梯度与 A 的删除影响相关，但与 B 不相关，见 `PRUNING_DELETION_RESULTS.md`。FastGS 已经按多视角误差/贡献增密与剪枝，PUP 3D-GS 用二阶敏感度，LinearMask-GS 学习连续掩码。把“保护低 opacity 细节”当主创新缺乏支撑。

FastGS 作者论文的 Mip-NeRF 360 汇总（作者自己的协议，分钟）：标准 3DGS 为 20.93 / PSNR 27.53 / LPIPS 0.221；FastGS 为 1.93 / 27.56 / 0.261；FastGS-Big 为 3.58 / 27.93 / 0.216。快速臂与高质量臂间有明显间隙，且 FastGS-Big 已同时快于原 3DGS 并改善 PSNR/LPIPS。其源码 `public_baselines/fastgs` @ `44e02a5c1d5e9ed64d2ecd4af1cbba14ac92150f` 使用 10 个附加视角的误差区域计数和周期剪枝。不同论文/GPU 的绝对秒数不可直接拼接；新方案须对 **FastGS-Big 同协议复现**，不能只对普通 gsplat 赢 16%。

## 核心数学

标准前到后的像素合成使用有效 opacity `a(p)=q·G(p)`。若把一个高斯替换成两个**同位置、同协方差、同颜色、深度排序相邻**的子体，并希望出生瞬间任一像素透射率不变，子体应使用非高斯的点wise opacity 核：

```text
h(a) = 1 − sqrt(1−a) = −expm1[0.5 log1p(−a)]
(1−h(a))² = 1−a
```

两个相邻且颜色相同的子体合成后，对其前方/后方任意其他高斯与背景，像素颜色均与父体完全相同。若把子体有效 opacity 简单设为 `a/2`，合成后为 `a−a²/4`；`a=0.6` 时得到 0.51，差 0.09。该恒等式扩展为 m 个相同子体 `h_m(a)=1−(1−a)^(1/m)`，但本轮只讨论两个。

**固定 opacity/协方差的标准高斯子体一般无法精确实现该函数。** 假设 `h(qe^(−t))=q' e^(−kt)` 对所有 t≥0 成立。由 t→∞ 的一阶项得 k=1、q'=q/2；而 t=0 时 `1−sqrt(1−q)>q/2`（0<q<1），矛盾。因此必须有非高斯的暂态 kernel，或接受近似误差。公式本身是简单代数，研究贡献若存在，只能来自可训练、低成本的拓扑生命周期及实证优势，不能把平方根恒等式本身宣称为首创。

`transmittance_split_oracle.py` 对 10,000 组随机前缀/父体/后缀/背景和颜色验证：图像最大绝对误差 3.33e−16，透射率误差 2.22e−16，共享 opacity 坐标的中心差分导数误差 2.22e−10。`transmittance_split_oracle.json` 保存结果。这只是 FP64 单像素完整合成。真实 CUDA 的 early termination、alpha clamp、tie sorting、并行浮点次序可能破坏逐位等价。

进一步的 `transmittance_split_reference.py` 使用 `r=sigmoid(−logit)`，先计算 `s=(1−G)+G·r`，再在 s<0.5 时用 `1−sqrt(s)`、其余用有理化的 `G(1−r)/(1+sqrt(s))`；避免先把 `sigmoid(logit)` 舍入为 1 再做 `sqrt(1−a)`。10,000 像素的 PyTorch 参考中，FP64 最大图像/共享 logit 梯度差分别 3.33e−16/4.94e−17；FP32 分别 1.79e−7/2.58e−8，结果见 `transmittance_split_reference.json`。在 FP32 `logit=20,G=1`，直接表达式的反传产生 NaN，稳定表达式保持有限。FP32 父体原始 sigmoid 路径本身可能饱和并给出零梯度，所以“数学共享梯度一致”不等于与现有 FP32 CUDA 每项逐位相同；真实后端仍须专项验证。

## 为何值得研究，也可能失败

**真实后端的必要修正已验证**：P11 使用 `MAX_ALPHA=0.99`、单体阈值 `1/255` 和排除当前项的透射率早停 `1e-4`。原生 CUDA 反例表明，独立子体会因阈值、上界处理和中途早停破坏出生恒等式。隔离原型先对父响应截断，再让整对参与阈值/早停。初版整对 alpha 求和仍在全场景全部成对时产生最大 0.00208 图像差；改用 `A=a1+s1/(s1+s2)*(a2-a1)`、`s_i=sqrt(1-a_i)` 及同色精确的预乘颜色表达后，三个 1920×1080 视角、全部 260,530 个父体成对均通过原图像/VJP 门。最大 RGB 差 2.39e-7、alpha 差 0，所有检查的 VJP 相对误差 ≤1.78e-4。完整场景只验证共有父参数的梯度；独立子体梯度在小图参考中验证。固定父体覆盖/排序还不是支持自由子体运动的完整渲染器。

P11 room@2000 的先前 256 个高 absgrad 分裂候选取自真实检查点 `abae3768…`，保存原始 logits 经 sigmoid 后，opacity 中位 0.8607、90 分位约 0.9999967。这说明相当一部分候选不在 `a≈0` 的线性极限；若对它们简单半 opacity，中心透射率差可能大。但这些不是 FastGS 正式增密候选，原生 gsplat split 也**不是**简单半 opacity；不能把 `a²/4` 直接当成实际训练误差。既有 room 八组原生 split 的初始 A/B 损失变化有正有负：连续出生可能消除有害冲击，也可能延后有益的即时变化。

子体若保持完全重合且对称，其相对位置模式的一阶梯度为零，无法自行分开；必须给相对几何受控的小扰动，随后就不再具有严格图像恒等。高 opacity 在 FP32 中可饱和为 1，`log1p(−a)` 与自定义反传需避免 0×∞/NaN。非高斯 kernel 的每像素 sqrt/log 成本、排序成对相邻约束、暂态到普通高斯的退出转换，都可能抵消训练收益。先前的共有/相对 Adam 状态方案在 92 条局部分支未形成稳定终局优势，不可将其直接包装成本方案的已证组成。

## 实现和证伪顺序

**阶段裁决**：步骤 1 的出生算子通过；步骤 2 前必须解决的运动语义在当前“固定父深度整对”配置下未通过机会门。0.1σ 位移时，同 tile 子体对有 67.6%–94.5% 被其他高斯穿插；整对平均损失在 A/B 均没有改善未分裂模型。B 上物理排序的均值改善主要由一个视角贡献。故不对该配置继续做昂贵的 64/512 步训练；以下步骤保留为重新设计遮挡/退出机制后的条件性验证顺序，不是正在执行的队列。

1. 出生阶段的独立 PyTorch/CUDA 算子和 room 全分辨率共有 VJP 检查已完成，原始失败及稳定表达修正见 `SURVIVAL_PAIR_RESULTS.md`。下一道实现门是子体位移后的 union tile 覆盖、成组排序/遮挡语义及暂态退出；不能拿固定父体覆盖的出生原型直接当训练器。独立非重合子体只通过小图算子检查。
2. 在上述运动语义可用后，在 P11 room/garden/bicycle 真实事件上固定**同一分裂父体和新增点数**，对照原生 split、已发表的近似密度守恒 split、暂态精确核。出生时、受控位移后及 64/512 步分别测原损失、A/B 视角和事件成本；A/B 仍不等于正式未见视角。隔离 custom kernel、位移和 optimizer-state 改动，不把它们混为一项胜利。
3. 只有跨场景局部门超过重放差且新增 kernel/转换的完整成本有回收空间，才在独立 FastGS-Big 代码分支做完整训练。对照 FastGS、FastGS-Big、SteepGS/BOGausS 可复现实现；统计出生频率、暂态点比例、点数曲线、每步毫秒和总墙钟。若暂态开销超过可回收的训练节省，或质量只改善训练视角而不改善官方新视角，停止。
4. 完整 11 场景×3 种子同 GPU、数据、计时和评测，至少以 FastGS-Big 的质量—时间前沿为强对照。最终 PSNR/SSIM/LPIPS、时间到匹配质量、失败场景和区间全部报告；“与最新方法不相上下”和“原创”分别需要同协议性能证据与进一步全文/源码查重。当前两项均未成立。

已核对边界：BOGausS 的 density-preserving split 通过学习近似子体尺寸/opacity；SteepGS 使用分裂矩阵并给两个子体半 opacity，原文指出已有渲染式 opacity 修正仍不精确；Efficient Density Control v4 和后续 [Improving Densification](https://arxiv.org/abs/2508.12313) 的 Long-Axis Split 全文均明确把每个子体 opacity 调成父体的 60%，而非逐像素透射率精确因式分解；2DGH 已使用非高斯的 Gaussian-Hermite 核。故“守恒分裂”“非高斯 splat”都不是新主张。上述来源还包括 [BOGausS](https://doi.org/10.23919/EUSIPCO63237.2025.11226626)、[SteepGS](https://arxiv.org/abs/2505.05587)、[Efficient Density Control v4](https://arxiv.org/html/2411.10133v4)、[2DGH](https://arxiv.org/abs/2408.16982)。本地保存 HTML 及 hash 于 `topology_sources/`。这是有界查重，不是原创认证。

**速度—质量验收边界**：出生瞬间图像守恒只避免一次拓扑冲击，不自动提高最终画质；两个子体及暂态非高斯核还可能增加每步成本。即使局部质量改善，若完整全分辨率训练的总墙钟或达到同等正式未见视角质量的时间不低于强基线，也不能把它称作满足“更快且更好”的优化。半分辨率主训练加稀疏全分辨率侦察已因用户目标与已有质量证据退出主线。

**直接先行工作**：[Revising Densification](https://arxiv.org/abs/2404.06109) §3.3 已给出 `q'=1-sqrt(1-q)` 和 `q/(1+sqrt(1-q))`，用于 clone 的标量 opacity；作者明确说明该校正只有中心完全去偏，离开中心仍有偏差，普通 split 则保留原 opacity。故平方根公式和有理化式不是本项目原创，尚待检验的主张只能是逐像素核、成对合成与可训练生命周期的整体机制及实证收益。
