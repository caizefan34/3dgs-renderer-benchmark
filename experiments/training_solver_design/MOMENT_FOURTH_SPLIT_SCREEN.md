# 四阶矩补偿分裂信号：alpha 合成反例使当前方案退出强候选

2026-09-27。目标保持不变：每步原分辨率、原训练损失，在完整墙钟更短的同时提高正式未见视角 PSNR/SSIM/LPIPS，并与 FastGS-Big、TurboGS 等强系统同协议比较。本文件完成数学机会筛查和有界先行工作核对。**新增 alpha 合成反例表明：即使采用零位移精确保真的子体核，矩补偿后的真实 opacity 响应仍有二阶项，不能用纯四阶 Hermite 信号代表实际分裂。当前方案不进入生产 CUDA 或长程训练。**没有 3DGS 训练收益、成本或原创性结论。

## 研究假设

普通 split 的二阶形状变化可与现有 covariance 更新重合。若对子体 covariance 做矩补偿，新增的领先形状响应变为四阶。候选机制只在**正常全分辨率反向传播**中，对少数待增密父体累积该四阶图像方向的损失伴随量；不另渲染低分辨率图、不新增长期存在的 Hermite primitive。若多视角累积能比 absgrad、FastGS 和 SteepGS 的判据更好预测真实有限分裂的长程质量/计算收益，才考虑按同预算执行标准 Gaussian split。这个方向可能减少无效点数及后续计算，并把容量留给真正无法用位置/尺度修复的细节；这些都只是待验证因果链。

## 密度极限及实际限制

对归一化可加的一维 Gaussian 密度 `phi_sigma`，位移 `±h`、子体方差 `sigma²−h²`、各占一半质量，要求 `h<sigma`。其傅里叶变换与父体的比值为 `exp(h²t²/2)cos(ht)=1−h⁴t⁴/12+O(h⁶)`，所以

```text
0.5 phi_sqrt(sigma²−h²)(x−h) + 0.5 phi_sqrt(sigma²−h²)(x+h)
  − phi_sigma(x)
  = −h⁴/(12 sigma⁴) H4(x/sigma) phi_sigma(x) + O(h⁶),
H4(z)=z⁴−6z²+3.
```

三维沿方向 `u` 是同一方向四阶导数；投影到图像后必须使用相机 Jacobian 和实际 2D covariance 计算方向。这里的“矩补偿”表示**密度**的零至二阶矩相等，不表示图像损失下与旧参数 Jacobian 正交。独立 FP64 一维 oracle 用普通图像 L2 将 `H4*phi` 投影到旧的幅度、位置、方差切向量后，剩余范数仅占原四阶方向的 **0.4781**；剩余能量约 **22.86%**。因此不应把原始四阶梯度称为“新容量的纯梯度”。

| `h/sigma` | 四阶近似的相对 L2 误差 | 扣除旧切空间后的相对误差 | 扣除后的方向余弦 |
| ---: | ---: | ---: | ---: |
| .500 | .3107 | .4321 | .9825 |
| .350 | .1576 | .2353 | .9959 |
| .250 | .0816 | .1262 | .9989 |
| .175 | .0403 | .0635 | .9997 |
| .125 | .0207 | .0328 | .9999 |

小位移时方向吻合，但真实响应幅度按 `h⁴` 缩小，可能被相机抽样、遮挡和 FP32 归约噪声淹没。位移达 .5σ 时，有限编辑与四阶近似已有 31% 差距，条件化后约 43%。这不支持用一个 infinitesimal 分数直接决定有限 split。

更关键的是标准 3DGS 的 alpha 合成不是可加密度。两个重合、各为半 opacity 的子体在 `q=.6`、Gaussian 中心的组合 alpha 为 `.51`，比父体 `.6` 少 `.09`，与 `h→0` 无关。即使把每个子体改成零位移可精确保真的非 Gaussian 核 `alpha_child=1−sqrt(1−f_child)`，也不会恢复四阶领先响应。令 `a(x)=q exp(−x²/2)`，`f_±(x)=q phi_sqrt(1−h²)(x∓h)/phi_1(0)`，并使两子体相邻、同色；由密度矩补偿有 `f_±=a±h a x+O(h³)`，但 alpha 合成得到：

```text
alpha_pair = 1 − sqrt[(1−f_+)(1−f_−)]
alpha_pair − a = h² a² x² / [2(1−a)] + O(h⁴).
```

这是**二阶**且非负的 opacity 响应，不是 `H4/O(h⁴)`。FP64 数值 oracle 在 `h=.125σ` 时二阶式相对 L2 误差 .0304，缩步后持续下降；在 `.25σ` 为 .1185。它只对应一维相邻同色、没有其他高斯穿插的理想合成，已经足以否定“密度四阶就是 alpha 四阶”的外推。硬 alpha cutoff、提前停止、物理深度穿插及颜色/SH 更新进一步改变真实响应。先前 `SURVIVAL_MOTION_RESULTS.md` 已显示仅 .1σ 位移时两个子体在 67.6%–94.5% 的共同 tile 中被其他高斯穿插。**密度极限不能冒充真实渲染器的分裂导数。**

**遮挡顺序还有独立的不可能性**。设原父体 `P(a,c)` 在另一高斯 `B(b,d)` 前；分裂后同色的前子体 `P1(a1,c)` 和后子体 `P2(a2,c)` 将 B 夹在中间，并令 `(1−a1)(1−a2)=1−a`，即整家族最终透射率完全相同。任意背景颜色均被同样的总透射率乘上，但前到后合成的颜色差精确为

```text
C(P1, B, P2) − C(P, B) = (1−a1) a2 b (d−c).
```

只要后子体有贡献、B 有 opacity 且颜色不同，就一般不为零。1,000 组 FP64 随机 RGB/alpha 检查最大公式误差低于 `1e−15`。因此**任何只保证两个子体总透射率相等、却允许第三方 splat 穿插的规则，都不能保证任意场景出生图像不变**。这是合成代数结论，不是对特定训练轨迹的性能判断。

## 原实施草图与先行边界

原设想是在原生反向已形成 `dL/dalpha` 的位置，对少量候选父体累积 `dL/dalpha * qG * H4(z)`，以避免第二遍渲染。上述二阶反例表明，该值**不是**合法连续 alpha 分裂的领先导数。若要修正，必须改为真实 opacity/透射率的导数，再处理真实支持、物理深度排序和未来计算成本；这实质上回到之前已遇到质量/排序障碍的透射率分裂路线。当前不投入 CUDA 实现。即便某四阶分数偶然与收益相关，也只能称经验统计，不能声称基于分裂导数的机制。

- [SteepGS](https://arxiv.org/abs/2505.05587) 已把分裂矩阵/Hessian 信号累积进训练反向；“在反向中算分裂信号”不是新颖性。本文可能的区别是**协方差补偿后的四阶方向**及其对未来计算成本的条件校准，但尚未对 SteepGS 完整代码和更新论文做穷尽查重。
- [2DGH](https://arxiv.org/html/2408.16982) 已把包括 `H4` 的 Gaussian-Hermite 基函数用于可训练 splat，并采用 coarse-to-fine 引入系数。`H4` 本身及“逐级开启 Hermite”不新；论文还报告其永久 Hermite 表示的前向 FPS 比 2DGS 低约 20%–30%。本假设只考虑短期/诊断性四阶分数、最终仍为标准 Gaussian 输出，性能须独立验证。本地原文快照 `topology_sources/2dgh.html` SHA256 `d40b4b89f6dad16903d1c9ce42ead34a95599a93ebb36ab76fb6ec4dcf6a1317`。
- [Revising Densification](https://arxiv.org/abs/2404.06109) 已讨论 opacity 修正；矩守恒分裂亦有直接先行工作。因此不能把“守恒”或“不损伤出生图像”作为首创声明。

## 阶段裁决与将来可能的重新开启门

1. **当前停止**：密度 `H4` 信号不再作为下一项 GPU 候选，更不用于 30K 训练。此裁决只针对它对实际 alpha 分裂的推导，不证明所有四阶表示都没有价值。
2. 只有提出在非零 opacity、真实物理排序下仍成立且成本可回收的替代导数，并在 room/garden 的真实有限分裂与 64/512 步配对收益中优于 absgrad、FastGS、SteepGS，才重新开启。必须保持全分辨率并计入全部评分/构造成本。
3. 若重启并通过局部门，最终仍需独立场景/种子、正式未见视角质量、完整墙钟与同协议强系统比较。现有数学 oracle 对这些结论没有证明力。

执行 `python experiments/training_solver_design/moment_split_fourth_oracle.py` 会重建 `moment_split_fourth_oracle.json`。这个 oracle 只验证归一化一维密度极限、图像 L2 下的旧方向重合、相邻同色 alpha 合成的二阶项、普通半 opacity 在零位移仍不守恒，以及穿插高斯的代数恒等式；它没有 GPU、完整渲染器、优化器或训练结果。
