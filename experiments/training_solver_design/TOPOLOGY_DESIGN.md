# 让几何修复与增密竞争训练预算

2026-09-26。目标：更短训练时间、更高新视角重建质量。

**建议主攻：有限拓扑编辑的条件收益控制。** 对一个区域先估计现有高斯可完成的修复，再衡量真正执行 split 后还剩多少独立收益，同时考虑它增加的后续训练成本。输出仍为标准 3DGS。

状态更新：**当前版条件评分未通过真实状态机会门，不进入生产 CUDA。** 已完成 room/garden 真实 2,000 步检查点的配对诊断及 room 512 步扩展，结果见 [REAL_TOPOLOGY_RESULTS.md](REAL_TOPOLOGY_RESULTS.md)。下面保留原规格与假设；没有完整训练收益，不能宣布首创、SOTA 或已击败 FastGS。此前 SH 消元主线也已关闭，历史证据在 DESIGN.md。

## 1. 要解决的结构性问题

同样的高残差至少包含三种情况：

1. 一片表面的位置或深度存在系统偏差，现有高斯协调移动就可能修复。
2. 原高斯的形状、透明度或外观未拟合好，调现有参数就可能修复。
3. 当前表示不能同时表达多条边、薄结构或遮挡关系，需要新增自由度。

研究假设：把前两种误差也当作容量不足，会增加后续每步计算，并可能让颜色与冗余高斯掩盖几何误差。低成本地区分三者，有机会同时改善质量与用时；尚待真实训练状态验证。

核心问题是“允许同预算旧参数优化后，这次编辑还值不值”，而不是单看残差、点数或梯度。

## 2. 分裂响应可能与旧自由度重复

先考虑归一化、可加的 Gaussian 密度，**不是直接将其等同于 alpha 合成图像**。设 φΣ 为协方差 Σ 的高斯，D_u 为方向导数，对称分裂有：

```text
1/2 φΣ(x−μ−hu) + 1/2 φΣ(x−μ+hu)
  = φΣ(x−μ) + h²/2 D_u²φΣ + O(h⁴).
```

已有协方差变化 Σ→Σ+h²uuᵀ 产生相同的二阶项。因此“分裂产生响应”不等于“增加旧表示没有的能力”。若子体使用 Σ−h²uuᵀ，并保持平均位置和总质量：

```text
1/2 φ_(Σ−h²uuᵀ)(x−μ−hu) + 1/2 φ_(Σ−h²uuᵀ)(x−μ+hu)
  = φΣ(x−μ) − h⁴/12 D_u⁴φΣ + O(h⁶).
```

条件为 Σ−h²uuᵀ 正定。对称性消去奇数阶项，协方差补偿消去二阶项。只在零分裂处检查一阶导数会漏掉分裂；只看二阶密度变化也可能重复计算已有 scale 能力。这是标准 Gaussian 分析的应用，不是新概率论定理。

3DGS 还有更直接的障碍。原 alpha=o·g(x)，两个重合、opacity 各减半的子体得到：

```text
alpha_pair = 1 − (1−o·g/2)² = o·g − o²g²/4.
```

零位移分裂也不保证渲染不变。把 child opacity 改成 1−√(1−o) 只在 g=1 匹配；逐像素精确匹配需要 1−√(1−o·g(x))，通常不是常数乘 Gaussian。不同颜色、遮挡和排序进一步改变响应。

**因此采用真实有限编辑的渲染差，包含父体移除、子体出现与遮挡变化。矩守恒可以生成候选，不能代替真实渲染验证。**

## 3. 有符号的有限编辑判据

设一组训练视图上的加权残差为 r=R(θ)−y，旧参数局部图像响应矩阵为 J。候选 a 执行一个完整合法编辑：

```text
b_a = R(edit_a(θ)) − R(θ).
```

b_a 是真实图像差，不是零 opacity 新生点的梯度。split 必须包含父体被替换的影响，不允许任意插值成一个不存在的渲染模型。

先用相同 J、相同正则构造两臂筛选代理：

```text
E0 = min_d  1/2 ||r + Jd||² + λ/2 ||d||²
Ea = min_d  1/2 ||r + b_a + Jd||² + λ/2 ||d||²

Pλ = I − J(JᵀJ+λI)^−1Jᵀ
Δa = E0 − Ea = −b_aᵀPλr − 1/2 b_aᵀPλb_a.
```

λ=0 时用伪逆；λ>0 时 Pλ 不是正交投影。该恒等式仅适用于无约束线性修复。若使用盒约束，须分别求解两臂，不能沿用闭式公式。

与此前“新增列系数自由取值”的非负 Schur 收益不同，这里编辑幅度已确定，**Δa 可以为负**。方向与误差相反但幅度过大的编辑应被拒绝，不能靠任意缩放图像差制造收益。

b_a 完全在旧 J 列空间内且 λ=0 时，Δa=0：旧参数可复制其局部收益。这不意味着长期永远无用；子体后续独立运动仍可能提供更多能力。

最终执行必须回到参数空间：不编辑臂与编辑臂各自做有界修复并真实重渲染，使用宿主 **0.8 L1+0.2 D-SSIM** 判断。编辑臂的 Jacobian J_a 可能不同；共同 J 的闭式分数只用于筛选，不是完整非线性反事实问题的精确解。

## 4. 最小实现与协调几何修复

初版保持宿主候选池、split 初始化、普通 Adam、SH 升阶和 pruning，**只替换增密选择判据**，隔离贡献。不同时换优化器、损失与初始化后归因给此判据。

选择判据通过机会门后，再考虑协调几何修复：

- 通过 3D 邻近与多视图共同可见性构造小组，避免混合相邻的不同表面。
- 每组 3 个共同平移、3 个共同 log-scale、1 个 opacity、3 个 DC，以及当前 Adam 的几何/外观两个方向，共最多 12 个响应方向。
- 这是低维筛选近似。高阶 SH、独立旋转和组内非刚性运动未充分包含，剩余误差不能直接称为“旧表示无法拟合”。离线 oracle 必须扩大修复空间，或用完整 Adam 短程修复检查误判。
- 协调移动作为待比较动作。如果不胜过同预算完整 Adam，就只保留选择判据，不强行保留这一模块。

开发初值：仅在宿主增密事件做决策，每个活跃区域最多评估 3 个候选。先固定已有候选验证排序，再考虑 split 幅度搜索。这些数字未经调优。

训练内部 A 组视图用于估计，B 组用于重新渲染检查；B 不参与该次反向修复，轮换分组。测试视图不参与选择。对不可见的视图不做无意义多数表决。

## 5. 真实训练成本控制

通过质量检查后，使用开发中的控制目标：

```text
U(a) = ΔL_B(a) − β[C_decision(a) + H·Δt_step(a)] − γ·uncertainty(a).
```

ΔL_B 使用原损失；β 的单位为 loss/秒；H 为剩余更新次数估计。该公式是需校准的启发式，不是已知精确的训练时间模型。

Δt_step 的特征包括 footprint、Gaussian–tile / Gaussian–pixel 交互、可见相机频率、SH 和 optimizer 访存；不只看点数。分裂缩小 footprint 时，增量成本可能为负。重叠候选的独立收益不可直接累加，采用低冲突小批次并验证合并效果。

潜在提速来自：减少无效容量带来的后续每步成本，以及协调修复可能减少所需步数。两者均未实测。

预算示例：假设所需步数比例 k=0.75，原每步 80% 耗时随交互变化，交互比例 q=0.5，其他成本不变，新增决策开销为原总时间 0.04，则 Tnew/Tbase≈k(0.2+0.8q)+0.04=0.49。**2.04× 只是这些假设的算术结果，不是性能预测。** 若 k=1、q=0.9，同样开销只给出约 1.04×。

低成本实现必须解决且计费的工作：

1. CPU 全 Jacobian、逐候选全图重渲染仅为离线 oracle，不能拿来声称训练加速。
2. 局部重渲染覆盖编辑前后 footprint 并集和 SSIM halo，保留完整 ray 上其他高斯、重排和背景影响；只渲染子体是错误的。
3. 稀疏 JVP 仅在候选区域积累小矩阵，计算仍随方向数增长；复用 backward 不等于免费。不存全场景像素×参数矩阵。
4. 只对验证过低冲突的候选批量试探；Python 循环的估计器不能摊销时，应停止而不是先投入复杂 CUDA。

## 6. 最可能推翻方案的情况

- **修复空间太小**：漏掉的旧方向被当成容量不足。必须与扩大空间/完整 Adam 校准。
- **短视拒绝**：有用 split 初始可能变差，需要后续独立运动才显现。配对短程与长程分支检查误杀；若即时分数系统性漏掉长程收益，不可硬部署。需要孵化式试探时也应计入额外训练。
- **反光、低纹理与标定误差**：图像误差不唯一确定几何。协调移动采用屏幕/深度信赖域，降低训练误差不证明表面更准。
- **编辑相互干扰**：不同视图可能发生重叠与排序变化；联合提交前真实验证。
- **泛化问题**：正式新视角 PSNR/SSIM/LPIPS 必须提升。几何质量另用有真值数据和 Chamfer/F-score 衡量。
- **状态污染**：两臂保持相同 optimizer 历史/RNG；存活点保留状态，子体使用相同规则。回滚包含 topology、optimizer、统计量和 RNG，不只 xyz。

## 7. 先行工作与真正待验证的区别

| 已核对工作 | 已覆盖内容 | 本方案需验证的区别 |
|---|---|---|
| [SteepGS，CVPR 2025](https://arxiv.org/abs/2505.05587) | splitting matrix、二阶 mean-shift/split 分解、最小特征值指导分裂 | 有限 alpha 编辑在旧位置/尺度/外观修复后的条件收益、跨视图验证和后续成本。不能仅以“区分移动与分裂”自称新颖。 |
| [A New Split Algorithm，2024](https://arxiv.org/abs/2403.09143) | 零/一/二阶矩守恒分裂 | 矩守恒不是本文创新；将其用于揭示重复方向，真实 alpha 编辑验证仍不可省。 |
| [FastGS](https://arxiv.org/abs/2511.04283) | 多视图高误差像素指导增密、贡献指导剪枝 | 扣除旧参数可完成的修复，而非仅统计多视图高误差 footprint。 |
| [Taming 3DGS](https://arxiv.org/abs/2406.15643) | 预算化容量控制与高效后端 | 有限编辑条件收益与剩余交互成本；“有预算”本身不新。 |
| [3DGS-LM](https://arxiv.org/abs/2409.12892) / [3DGS²](https://arxiv.org/abs/2501.13975) | 二阶/分块优化 | 协调修复只是对照动作，不能以采用二阶法宣称贡献。 |
| [OGC](https://arxiv.org/abs/2609.28997) / [Instant Colorization](https://arxiv.org/abs/2604.17155) | 固定几何 SH 拟合与迭代求解 | SH 求解器已退出本项目主创新定位。 |

本轮读取前 3 项的方法原文，网页 SHA256 与文本在 topology_sources/；其他见已保存审查。这不是穷尽查重，仍需检查 adaptive approximation、topological derivatives、splitting steepest descent、神经元分裂中的等价条件收益工作。投影/Schur 公式是标准数学，可能贡献是低成本真实 3DGS 决策机制及实证，不是公式本身。

## 8. 已有检查与实验验收

运行 `python experiments/training_solver_design/topology_oracle.py`，结果在 topology_evidence.json：

- 100 组随机两臂线性修复，公式与直接优化的最大差 1.78e−14。
- 旧参数能复制编辑时，未条件化收益 0.5、条件收益 0。
- 正确方向但过冲的编辑得到 −1.5，不能只看残差相关性。
- 漏掉一个旧方向得到 0.5 虚假容量收益，补回后为 0。
- 1D 固定协方差对称分裂阶数约 1.998，矩守恒约 4.013；四阶极限相对误差约 0.00332。
- opacity=0.6 时，两个半 opacity 重合子体中心少 0.09 alpha；匹配中心后边缘仍不匹配。

以上只验证代数和表示反例，**没有训练性能含义**。

决定性实验顺序：

1. 从 room/bicycle/garden 有来源和 Adam 历史的早中期状态做离线配对编辑。对同一候选比较 absgrad、FastGS 风格分数、SteepGS、原始有限编辑、条件有限编辑。测收益排序、误杀有用 split、跨视角与長程稳定性。不能扰动收敛 PLY 冒充早期训练。
2. 固定候选数、新增容量、试探时间分别比较；再独立加入协调修复与成本项。额外候选渲染必须计时。
3. 继续门：在独立状态上，条件评分优于未条件化与廉价评分；估计器额外时间暂以总训练 3% 为上限，且可由实测收益回收。3% 是研发门槛，不是已达成值；失败就停止该实现。
4. 通过后才做生产 kernel 与确认集。强对照为同后端 gsplat+fusedSSIM、FastGS、可复现的 SteepGS/其他方法；官方完整系统另比，不能用共享后端消融代替系统能力。
5. 挑战目标：同 GPU/数据/质量标准 time-to-quality 至少 2×；同墙钟 PSNR 至少 +0.3dB，SSIM/LPIPS 不劣。这是目标，非结果。先导至少跨过 1.3× 且质量不劣才值得扩大；正式报告多场景配对区间与失败场景。

规格形成时尚未运行 GPU；随后真实检查点诊断已完成，具体边界与负结果见 REAL_TOPOLOGY_RESULTS.md。没有修改 frozen P12 或官方基线，研究目标仍未完成。
