# 无额外渲染的空间梯度预测：待验证研究候选

日期：2026-09-27。原目标仍为更快训练、更高重建质量；本文不是已取得训练优势
或新颖性的声明。控制变量、动量降噪、矩拟合与 Gauss–Hermite 求积均有成熟先行工作。

## 为什么改变当前路线

garden 的共享排序列表已经验证完全一致，但固定状态下令第二次交集/排序免费，
三个视角仍慢于原生：24.426/19.916/19.038 ms 对18.482/19.588/18.706 ms。
这只关闭“单靠消除第二次排序即可胜出”的主张，不否定未来不同光栅内核能改变成本。

一个无需粗层渲染的替代是利用已有每高斯梯度预测 c_i，按当前投影中心分配到块。
设 a(i) 为分配块，采样组 S 的概率为1/4：

`g_hat_i = g_sampled_i + c_i - 4*1[a(i) in S]*c_i`。

无论中心分配是否精确，在抽样前冻结 c_i 与分配就保持条件无偏。但garden三个
视角里，Adam已保存一阶矩经偏差修正后的预测，beta=1使所有组噪声略增；甚至
拿当前完整细图梯度作为不能免费获得的参考，按中心分配也经常更差。
不能仅因为它便宜便进入训练，也不能把oracle beta变成已实现的策略。

## 空间矩拟合的可检验机制

高斯的局部导数有符号。对2D高斯 `alpha=o*exp(-delta^T Q delta/2)`，假设
其有效alpha伴随梯度在空间上为 q(p)。均值梯度包含 `q*alpha*Q*delta`。
即使q为正常数，左右区域的均值梯度也符号相反，而完整积分为零。因此仅保存
总梯度再乘空间权重，无法一般地还原这种局部抵消。这是明确反例，不是当前
数据所有失败的已证因果解释。

用已有的屏幕空间梯度作为有效伴随场的矩：

```text
M0 = o * g_opacity
M1 = inverse(Q) * g_mean
M2 = [[-2*g_Qxx, -g_Qxy], [-g_Qxy, -2*g_Qyy]]
```

取 `Q=A^T A`，`R=inverse(A)`，将Gaussian标准化为 `delta=R*z`，则一个匹配
这些矩的二次Hermite多项式为：

```text
B = R^T * g_mean
H = (A*M2*A^T - M0*I)/2
P(z) = M0 + B^T*z + z^T*H*z - trace(H)
```

标准正态每轴3节点 `[-sqrt(3),0,sqrt(3)]`、权重 `[1/6,2/3,1/6]`，形成9节点。
每节点的质量权重 `s=w*P(z)` 可以有正有负，构造：

```text
g_mean_node = s*A^T*z
g_conic_node = [-s*dx^2/2, -s*dx*dy, -s*dy^2/2]
g_opacity_node = s/o
```

求和恢复输入的均值、conic、opacity梯度。颜色梯度只能先按Gaussian求积权重
分配，没有从颜色总梯度凭空恢复更多空间信息。将节点按投影位置分配到块，
形成空间控制变量。预测值停止求导，通过潜变量的线性代理损失将其送回同一
投影与SH图；理论上不需要第二次场景渲染。

CPU双精度测试验证任意梯度的矩重建、分块总和，以及总均值梯度为零但局部
导数不为零的反例。浮点条件数、无效conic和图像边界仍须GPU审计。

## 必须分开的两个问题

1. **表示机会**：假设已经有当前完整细图的屏幕空间矩，该9节点近似能否降低
   真实块采样的原始梯度/Adam更新误差？这是本轮oracle，完整渲染仍用于诊断。
2. **可用算法**：如何在没有当前完整细图反传的情况下得到准确且便宜的矩？
   现有跨视角Adam一阶矩已给出负结果。缓存过期、视角迁移、每视角缓存容量、
   刷新开销与拓扑变化均未解决。不能用本轮fresh oracle掩盖这个缺口。

只有两个问题均通过，才测实际稀疏训练与完整质量—时间曲线。此时还要计入
预测器构造/存储/刷新、视角调度及非线性增密，而不是只报渲染时间。

先行工作边界：SAGA (arXiv:1407.0202) 与STORM (arXiv:1905.10018) 的官方
摘要已查证；“利用历史梯度/动量做方差缩减”不是新贡献。更具体的空间矩控制
变量仍需源码/全文级查新，当前搜索没有找到某词不构成首创证据。

## 可实现的缓存训练候选，而不是免费fresh参考

若fresh表示机会通过，下一项要测试**按视角保存9通道潜变量梯度**：投影均值2、
conic3、opacity1、颜色3。这是拟议算法，尚未实现或验证，不能计入当前收益。

1. 完整渲染某训练视角时保存其每个高斯的9通道梯度，作为该视角缓存；初始化
   和以后任何刷新成本均计入总训练。新视角/新高斯无缓存时不能假装已有预测。
2. 再次选择该视角时，在当前投影/conic下把缓存梯度拟合为空间矩，用9节点
   计算所选块的预测。冻结缓存与分配，再抽样或按预先确定的抽样实现计算。
3. 同一细层图的损失加上线性代理 `beta*sum(latent*(cache_full-cache_sampled))`，
   一次反传同时得到模型更新梯度与校正的潜变量梯度。不能对cache求导。
4. 用校正后的潜变量梯度更新该视角缓存。更新发生在本次估计器之后，避免把
   本次抽样信息泄漏进其控制变量。EMA速率需提前固定并通过实验，不在这里
   宣称某个速率已合适。拓扑变化必须按高斯持久ID处理出生、删除、替换。

这将“获取当前完整梯度”的成本换成缓存陈旧度与存储问题，而没有消除问题。
当前半球视角间共用Adam历史已失败，不能将它当作这个视角缓存的现成解法。
同一视角也可能隔上百步才再出现：在32/128步真实参数更新后的保真度，应先于
大规模训练验证。首次完整缓存、全部构造/读写、维护与失败刷新都必须计时。

容量估算只作设计边界：当前SH3模型每高斯原始参数59通道，缓存潜变量梯度
只需9通道（同精度约6.56倍压缩）。garden 1,841,621点、185视角全密集缓存
FP32约12.26 GB，BF16约6.13 GB，均为十进制估算，不含其他训练内存。只存
可见ID可减少容量，但索引与拓扑成本未测。BF16精度影响也尚未测试。

不能提前声称跨视角泛化、免费缓存或实用显存。若同视角旧缓存迅速失去相关性，
或预测构造/存储超过稀疏渲染节省，就关闭当前算法，不以fresh oracle冒充成品。

## 陈旧度失败后的有限修正：传递伴随场而不是旧梯度数值

SPATIAL_PREDICTOR_RESULTS.md记录固定旧潜变量梯度的失败。一个更具体、仍需
检验的假设是把参考时刻的二次有效伴随场q(p)固定在屏幕坐标中，再对当前高斯
重新积分。旧梯度随当前几何直接使用与该操作不同。

参考几何为mu0、R0、opacity0，拟合多项式为P0(z0)，质量
`Z0=2*pi*opacity0*det(R0)`。当前节点p=mu_t+R_t*z：

```text
z0 = inverse(R0) * (mu_t + R_t*z - mu0)
node_mass_t = w * (Zt/Z0) * P0(z0)
```

再按当前几何的均值/conic/opacity导数形成节点梯度。颜色伴随场先按常量处理，
总颜色梯度随Zt/Z0缩放。完整与采样控制变量必须都用这个同一传递定义。

独立CPU测试对固定的任意二次屏幕场，改变位置、协方差、opacity后，节点梯度
与Gaussian积分的自动微分一致（1 passed）。它不证明真实训练的有效伴随场
在更新中保持不变：图像残差、遮挡和颜色都会改变q。GPU对照须在同一条冻结
拓扑轨迹上同时比较固定旧梯度与该场传递，避免将重放差异归因于算法。
transported_adjoint_predictor.py是研究辅助实现，尚非紧凑缓存或生产内核。
