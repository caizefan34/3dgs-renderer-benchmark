# Multi-view observable birth layouts: urgent source and P0 audit

2026-09-28. No GPU work, trainer edits, or Luna-file edits. The newly supplied event counts are root-reported snapshot measurements, not independently recomputed here.

## Verdict

**Generic camera-Jacobian/frequency-guided reduced-axis splitting: NO-GO for originality.** SAD already contains it. **A narrower full cross-axis, parent-whitened birth-layout hypothesis: GO for a bounded geometry/work-share diagnostic only; GPU quality P0 is not justified until that gate passes.** There is no certified original mechanism yet.

The distinction is between independent decisions on a parent's existing axes and replacing the complete child layout using correlations between those axes. A proposal that merely changes each native `k` or chooses the longest/best eigenvector and makes two children is too close to existing work.

## Four requested boundaries

1. **[SAD](https://arxiv.org/html/2604.28016v1), sections 3.1, 3.3–3.5, 4.3.** The paper already projects each principal axis by the camera Jacobian, chooses independent anisotropic counts, aggregates views, and forms an `nx * ny * nz` grid. Equation 7 explicitly uses `eta_proj = sqrt(v_k^T Sbar v_k)` for directional frequency. Its ablation gives worse LPIPS than the scalar-frequency variant; the authors attribute this to insufficiently optimized rotations and the usefulness of spare capacity for later position/rotation refinement. Thus camera Jacobians, frequency tensors, directional thresholds, and fewer children along weak parent axes are not new. The remaining distinction would be retaining the full off-diagonal matrix and replacing the entire coordinate layout, not another version of Eq. 7.
2. **[SteepGS](https://arxiv.org/html/2505.05587v1), section 4 and appendix A.** Already derives a splitting matrix and selects a least-eigenvalue direction, with two opposite offspring sufficient for its local descent objective. Generic spectral splitting, minimal offspring or loss-aware direction selection is occupied. The possible distinction is a *finite frequency-resolution layout with potentially more than two children and retained weak-direction covariance*, guided by a multiview projection metric rather than the loss splitting matrix. That distinction is descriptive, not a novelty certification.
3. **[BOGausS accepted manuscript](https://hal.science/hal-05444229/document), sections III, IV-B, V-B; [DOI](https://doi.org/10.23919/EUSIPCO63237.2025.11226626).** Already derives multiview positional/scale precision from cameras, then uses a scalar trace-based approximation for update scales/minimum size. Its splitting is a density-preserving two-child longest-principal-axis operation with opacity/scale adaptation. Camera-aware reconstruction confidence and density-preserving low-count splitting are occupied. The potential difference is using the full frequency-weighted cross-axis spectrum to determine a finite child layout. Combining BOGausS's precision idea with SAD's tensor is not by itself evidence of a substantial contribution.
4. **[ShorterSplatting](https://arxiv.org/html/2603.09277v1), sections 4.1–4.2.** Globally shrinks scales and uses a compositing-weight entropy penalty to shorten pixel lists. The proposed birth-layout replacement could retain the original objective and make only event-local representation changes, unlike scale resets/entropy. But both target accepted rendering work; the cost target cannot carry novelty. Fewer children need not mean shorter pixel lists.

Additional boundaries: [QIRF](https://arxiv.org/html/2607.18067v1) already constructs overlap/response matrices, performs generalized eigenanalysis, and selects representative existing Gaussians from a dominant local function subspace. This is inter-primitive compression, not the proposed intra-parent coordinate layout, but invalidates broad claims about first using subspaces to reduce Gaussian redundancy. [Only What Was Seen](https://arxiv.org/abs/2609.28997v1), published 2026-09-24, uses an observation Gram matrix to compact view-dependent SH appearance; only its API abstract was inspected here. It is another boundary against claiming camera-observed subspace compaction generically. 2DGS already changes primitives to planar splats; forcing a rank-two covariance is not an appropriate novelty fallback.

## The specific mathematical opportunity

Write the parent covariance as `Sigma = L L^T`, with `L = R diag(s)`. For visible camera `v`, use dimensionless `A_v = J_v W_v L` and a frequency-squared screen tensor `F_v`. Define `H_v = A_v^T F_v A_v`; aggregate positive-semidefinite matrices with fixed visibility weights, `H = sum_v w_v H_v`. This is a *frequency-observation metric*, not a true photometric Fisher/Hessian, because it omits colors, compositing derivatives and order changes.

SAD's directional axis information corresponds to diagonal quadratic forms in the fixed parent frame. If `H = lambda u u^T` with `u = (1,1,1)/sqrt(3)`, every parent-axis diagonal is `lambda/3` even though the response has rank one. Independent thresholding followed by a Cartesian product can therefore allocate multiple directions to one correlated response. This is a mathematical possibility, not a measured description of room or garden.

An actual different finite-layout operator would diagonalize `H = U Lambda U^T`, place child means at `mu + L U z_j`, and use child covariance `L U D U^T L^T` with positive `D`. Weak directions get no mean subdivision but retain their parent-scale variance inside every child; they are **not flattened away**. Strong directions get finite subdivisions. The general child covariance must be refactorized into native scale/rotation. This is not an arbitrary free rotation of an anisotropic parent: rotating `R` alone would change the scene.

For equal mixture weights and a centered layout, choosing `Cov(z_j) + D = I` preserves the parent's first two mixture moments. For a uniform k-point grid with spacing `sqrt(12)/k`, the center variance is `(k^2-1)/k^2`, so `D_ii=1/k^2` has this property. This identity assumes scale exponent one. Native source allows `scale_power` to differ, so inspect the actual capture/configuration rather than assume it. None of these mixture identities preserves alpha-composited rendering. Native SAD copies parent opacity to every child; changing the grid multiplicity changes opacity accumulation and occlusion.

The native pinned [split implementation](https://github.com/LinjieLyu/SADGS/blob/029814fb5ed773e4a794cec5115951a64f610ab8/scene/gaussian_model.py#L638) computes `ceil(sqrt(clamp(eta,min=1)))`, with a minimum of one, and multiplies the three counts. The nearby comment mentions a maximum of eight, but the inspected executable lines impose no maximum. Paper eta notation and code accumulators must be reconciled before using a new spectral threshold; silently squaring or square-rooting the wrong quantity is a confound.

## Main quality and cost risks

- A single perspective Jacobian has a viewing-ray null direction; multiple differently positioned cameras generally make the combined metric full rank. A six-camera subset may produce a false nullspace. Low texture frequency also does not imply geometric unobservability: silhouettes, occlusion ordering and unseen-view parallax remain relevant.
- Average eigenvalue truncation can discard a direction important to one camera. Require separate per-view discarded-response bounds, and inspect both a frequency metric and a geometric projection metric. A weak direction should remain weak across independent cameras, not only on average.
- At a large finite grid radius, the center Jacobian may not predict nonlinear perspective or depth-order changes. Thin leaves, fences and mixed foreground/background footprints are especially dangerous for garden.
- SAD provides direct negative evidence: stricter directional splitting can harm perceptual quality when early geometry/rotation is immature. Fewer child degrees of freedom may remove useful future optimization capacity even if immediate rendering agrees.
- Keeping variance in an unsplit direction can retain broad projected footprints. Removing children may uncover other Gaussians and increase downstream work. Count reduction cannot substitute for accepted contribution, list length, backward time and total-step measurements.
- “Use freed capacity for visible detail” is not implemented by deleting weak-direction copies. Reallocation is a separate intervention, with its own priors and confounds, and should not enter the first P0 claim.

## Minimal staged P0 recommendation

**Stage 0: bounded diagnostic, no new training.** Use only the existing room and garden event-1500 captures, before analytic split and without post-split prune/opacity cap. Start from every native three-axis split parent, not selected pretty examples. Reuse exported projections/structure tensors if present; otherwise export only the required statistics through the existing capture path. First accumulate geometric `G_v = A_v^T A_v` over all eligible training cameras. Exporting statistics costs time and must later be charged.

Report spectra, contributing-camera angular coverage, per-view discarded response, child-count reduction and the native accepted-work share of eligible families. Fix a conservative discarded-response threshold in advance (e.g. at most 1% of per-view trace on every active view, for geometry and frequency separately). This is a diagnostic threshold, not a claimed image-error guarantee. Reject a low-rank proposal if the discarded direction becomes significant in any check view. If even optimistically eliminating eligible families accounts for less than 10% of whole-scene native accepted contributions, stop before a layout implementation. Missing accepted-work data means the cost gate remains open, not passed.

**Stage 1, only after that gate: frozen finite replacements.** Reuse fixed disjoint fit/check training cameras; camera poses and existing structure statistics may inform the metric, but check-view RGB losses may not tune ranks/layout/opacity. Construct four complete-scene arms on the identical eligible parent set: native grid; full-rank spectral layout; reduced-rank spectral layout; and a deterministic count-matched coarsened native-axis grid. Use the same declared opacity policy for both spectral arms; copying native opacity initially avoids silently adding a fitted opacity method. If opacity correction is introduced, it needs its own common control. Retain rejected/untouched parents exactly and account for their work.

Check original full-image L1+SSIM, per-view PSNR/SSIM/LPIPS, geometry-sensitive crops selected without looking at results, accepted contributions, forward/backward/list work, full-step timing, and actual birth-construction time. Reduced-rank must beat or match full-rank spectral and count-matched axis control; otherwise the effect is just fewer children or a different frame. A reasonable fixed continuation gate is at least 10% less whole-scene accepted work and at least 5% less full-step time, with no mean quality-metric regression on check views and no severe single-view failure. Those thresholds are proposed here, not experimental results or guarantees.

Immediate equality is insufficient to claim better quality. A positive frozen test can authorize a short identical-order continuation from the complete optimizer state, followed by the existing final protocol. Continuation budget and stopping conditions must be frozen before running it. Do not claim a quality-plus-total-cost mechanism until downstream quality and amortized full training time improve. If the requirement is strict triple-quality improvement, simple noninferiority in this P0 does not meet it.

## Urgent source correction: aggregation and powers must not be made falsely equivalent

The concrete protocol in `CORRELATED_DIRECTION_BIRTH_20260928.md` was reviewed after the report above. Its requirement that `diag(sum_v w_v H_v)` numerically reproduce the captured native eta is generally impossible and should be removed. Its direct `k=ceil(sqrt(lambda))` is also inconsistent with the inspected source's eta units.

Pinned [`utils/freq_utils.py`](https://github.com/LinjieLyu/SADGS/blob/029814fb5ed773e4a794cec5115951a64f610ab8/utils/freq_utils.py) was saved as `astra_observable_birth_prior_20260928/freq_utils_pinned.py`:

- Line 238 sets `weights_valid = torch.ones_like(max_transmittance)[is_active_vis]`. Despite the later transmittance-weighting comment, the current weights are one.
- Wavelength mode lines 334–348 uses `wavelength_min=1/(sqrt(lambda1)+1e-5)` and `eta=axis_length/wavelength_min`, with an axis-length epsilon. Its quadratic metric is proportional to `A^T A`, with scalar squared-frequency factor; it does **not** use directional `S`.
- Projection mode lines 371–373 computes `sqrt(axis^T S axis)`.
- Lines 391–392 take the elementwise maximum over **all valid observations**, before high/mid/low classification. The maximum is not restricted to high observations.
- `train.py` computes average-high statistics but passes `max_eta_3ch` into analytic splitting. Split code then takes `ceil(sqrt(clamp(eta,min=1)))`.

Ignoring the small numerical epsilons for algebra, define `H_v=A_v^T F_v A_v`, where wavelength mode uses `F_v=lambda1 I` and projection mode uses `F_v=S_v`. Then `eta_v(q)=sqrt(q^T H_v q)`, native accumulated directional eta is `max_observations eta_v(e_i)`, and the source's count is a **fourth-root** function of the quadratic form: `k_i=ceil(max(1,max_v e_i^T H_v e_i)^(1/4))`. This is a description of the executable rule, not endorsement of its sampling-theory comments. The epsilons must be included when testing actual numerical parity.

Two further non-equivalences matter. A normalized weighted sum of matrices cannot generally reproduce separate axis maxima: for `H1=diag(9,0)` and `H2=diag(0,9)`, native maxima are `(9,9)`, but no convex combination has that diagonal. Also, the accumulated native eta was evaluated at changing parent positions, scales, rotations and footprints over prior iterations. Rendering twelve cameras at the event checkpoint cannot reconstruct those historical values from the checkpoint alone.

**Correct minimal gate:** first reproduce the exact single-view eta formula, active mask, tensor sampling and powers on the same frozen inputs; separately reproduce the captured native child counts directly from stored eta. Do not demand equality between fresh multiview statistics and historical eta. If the original observation history is not saved, label the new statistic a fresh checkpoint metric and treat comparison to the historical native grid as an intervention, not mathematical parity.

**Conservative directional aggregation:** an average/sum matrix may propose an orientation `Q`, but count decisions should use the unaveraged per-direction envelope `e(q)=max_valid_views eta_v(q)`, followed by the unchanged source mapping `k(q)=ceil(sqrt(max(e(q),1)))`. This avoids diluting a rare important camera. It does not make the full envelope quadratic: max of quadratic forms is generally not one quadratic form. Do not build a matrix by taking elementwise maxima of entries and claim it is the PSD envelope. A true matrix upper bound `B >= H_v` in Loewner order for every view would be conservative, but finding a tight one introduces another optimization; an unnormalized sum is an upper bound but changes the camera-count scale and may erase all savings.

Even directional envelope counts do not bound mixed directions. For a stronger geometry gate, let `D_native` be native child covariance in the parent-whitened frame and `D_new=Q diag(k^-2) Q^T` (adjust for the actual scale exponent). Compare `A_v D_new A_v^T` with `A_v D_native A_v^T` for every camera, with a fixed small screen-space tolerance. Frequency-weight the same comparison where appropriate. An approximate PSD upper bound on the difference prevents claiming a weak *mean* mode while increasing projected covariance in another camera. This may conservatively reject most proposals, which is a valid no-go result. It still does not bound alpha-compositing error or prove rendering quality.

Using directional `S` instead of the native wavelength scalar adds SAD's already published negative directional ablation as a confound. The first distinct correlation test should keep the actual captured eta mode and its single-view formula fixed, change only frame/layout and fresh-versus-historical aggregation with explicit controls, and report both differences. If no material opportunity survives the per-view envelope/geometry bound, stop; do not loosen thresholds to obtain low rank. Novelty remains unverified even if it passes.

## Room Stage0 result review: bounded NO-GO

Root supplied results from `/root/sadgs_joint_birth_stage0_20260928/room/stage0_geometry_report.json`: the A-only geometric child-count proxy decreases 42.55%; only 233/34,495 families meet the preregistered support rule (at least three A cameras and two B cameras); those families account for 0.671% of the historical children in the native three-axis group; their own proxy decrease is 5.85%. The reported smallest normalized eigenvalue median is 2.97%. This agent inspected local `joint_birth_p0_work/stage0_geometry_gate.py` to verify statistic definitions, but did not independently fetch or recompute the remote JSON. No new experiment was run.

**Decision: NO-GO for advancing this particular room-event/12-view eigenframe-birth proposal.** The evidence does not establish a sufficiently supported, substantial opportunity and is not a reason to proceed to frequency reconstruction, new layout CUDA, quality probes or continuation. This is an engineering/research stop decision under the fixed protocol, not proof that no full-view spectral method can work.

The 42.55% headline is not the relevant deployment population. Fit requires only one active A view, and a single camera's `G=A^T A` has rank at most two by construction. Consequently large low-rank savings over that set can arise from missing observations rather than redundant 3D representation. The qualified set is only about 0.675% of native three-axis families. Its historical children are about 0.336% of all children born in this room event. Even deleting every child in that qualified set would only bound *event child count*, not accepted contributions or wall time; the latter were explicitly not measured. Do not multiply the 5.85% geometry proxy by historical counts to report a native saving, because their quantities/weights differ.

If the 2.97% median is the report's covered-population `lambda_min(sum_A G_v)/trace(sum_A G_v)` (confirm that field when presenting the number), it directly contradicts a common nearly invisible direction for roughly half that population under a 1% all-view discarded-response criterion. For any unit dropped direction `q`,

`sum_v q^T G_v q / sum_v trace(G_v) >= lambda_min(sum_v G_v) / trace(sum_v G_v)`.

The left side is a trace-weighted average of the individual active-view discarded fractions. If its minimum is above 1%, at least one active A view must exceed 1%; a small mean score or choosing a different eigenvector cannot fix that. This statement is about geometry-only response and the measured views, not a photometric-error or novelty theorem.

The observation protocol has additional limits: cameras were selected by uniform positions in sorted filenames, not guaranteed angular/visibility coverage; `radii>0`, `cov2D[:,6]>.8` and opacity>.5 define the strict current ADC-active set rather than every contributing Gaussian; the historical split population came from earlier changing geometry; the gradient qualifier was omitted; B cameras were excluded from fitting Q but were used during prefix training. Thus low qualified coverage cannot prove the remaining families have no valid multiview geometry. It does show that this fixed protocol cannot certify them. B visibility alone is also weaker than passing the full B covariance/dropped-response criterion, so 233 is an upper bound on the presently support-qualified candidates before those checks, not a success count.

Do not rescue this version by reducing the coverage requirement, raising the 1% tolerance, using only the best view, replacing the original objective, or searching additional camera sets/checkpoints/scenes after seeing this result. No extra garden run should be launched solely to obtain a positive example. Preserve the raw NPZ/JSON/source identities and label the conclusion room-only; already-authorized independent work can be accounted for separately. Reopening needs a materially different mechanism or independent evidence addressing the failed causal link, rather than another threshold sweep.
