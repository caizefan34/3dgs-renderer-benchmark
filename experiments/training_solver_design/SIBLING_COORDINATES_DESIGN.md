# 在分裂时区分共有参数与新增相对参数

后续进展：单次分裂原型已实现，结果及数值检查见 `SIBLING_RESULTS.md`
与 `SIBLING_PROTOCOL.md`。下面保留提出假设时的设计。
`TRANSIENT_COORDINATES_DESIGN.md` 给出了零延伸相对历史下的明确回迁
契约，并通过独立 raw EMA 检查；它不保证切换后的更新步幅连续，也没有
实现完整训练或建立其收益。不同更新年龄不必妨碍原始矩变换，但必须
明确历史延伸、共同 EMA 权重和回迁后采用的时钟。

2026-09-26。**下一项研究假设，未验证算法，不是已实现的强优化。** 目标仍是更快训练和更高重建质量；该候选要先通过真实状态对照，不能用重参数化公式代替最终目标。

## 1. 与已经失败的方案有什么区别

已有实测不支持按即时编辑收益直接选择分裂，也不支持把全部新生参数统一换成 fresh-age Adam。BOGausS 已有 lifespan 和父子状态继承，因此它们不能作为主创新。

本次提出更具体的机制：**让分裂只给新增加的相对自由度创建新历史，共有运动继续使用已有历史。** 是否有效、新颖和足够便宜都未知。

两个子体的原始参数记为 θ₊、θ₋。对 xyz、log-scale、opacity logit、原始 quaternion、SH 分别使用：

```text
μ = (θ₊+θ₋)/2,   δ = (θ₊−θ₋)/2
θ₊ = μ+δ,        θ₋ = μ−δ
gμ = g₊+g₋,      gδ = g₊−g₋.
```

μ 控制两者共同变化，δ 控制彼此差异。必须在 decode 之后再做 scale exp、opacity sigmoid 和 quaternion normalization；不能对已经归一化的旋转随意相加。以上只是线性坐标与链式法则，不是新数学定理。

候选更新：μ 使用父体已有历史，δ 使用新历史；其他高斯仍按宿主训练。可尝试让整片结构的调整沿 μ 进行，新增细节沿 δ 形成。Adam 不具一般线性坐标不变性，这会改变优化轨迹，不能称为原生 Adam 的等价加速。

## 2. 历史继承的假设必须单独检验

`mμ←m_parent, vμ←v_parent` 并不天然正确。若编辑前后局部函数接近，且两子体梯度各约为父体一半，则 gμ 约等于旧梯度；但 native split 会改变 opacity 合成、位置、scale 和遮挡，这个关系可能不成立。

因此初版固定完全相同的 native split 输出，先测 gμ 与原父体梯度的方向/尺度关系。不能通过换一个更容易拟合的初始化掩盖状态继承的问题。明确对照 physical-child 的 0.5/0.25 父体统计：在完全相关、均分梯度的理想条件下，它对应 common-mode 的完整父体统计。BOGausS-inspired 0.2/0.04 继承也保留为已有强对照。

共有历史可能滞后，差异方向也可能需要较大的初期步幅。本轮 fresh-age 的负结果提醒我们：不得预先认定新历史更稳定或质量更好。

## 3. 单次分裂的最小机制对照

使用现成 room/garden 检查点和固定 256 个父体，不扩大场景或调整候选来寻找好结果。比较：

1. 原坐标、原生 Adam，以及重复原生分支。
2. μ/δ 坐标，两组仍采用相同旧时钟和零动量：隔离坐标改变。
3. μ/δ 坐标，μ 继承父体历史，δ 零动量但旧时钟：隔离共同历史。
4. μ/δ 坐标，μ 继承、δ 从新时钟开始：完整研究假设。
5. 原坐标的父体统计继承对照，避免把常见继承收益误称为新坐标收益。

FP32 编码/解码可能有舍入误差。先将候选初始化统一 canonicalize，再让所有对照从同一解码结果开始，验证初始渲染/损失及参数误差；不能拿不同初始函数做优化器比较。实际前向语义、损失、相机序列、学习率预算保持一致。

必须同时看 A 与扩展 B、不同观察窗口、配对重复差异。通过后才研究完整训练；若不优于已有继承或步长对照，停止这个具体实现。

## 4. 重复分裂与剪枝不能略去

单次浅层 sibling 试验不能自动成为完整训练器。合并、拆开或重新配对子体时，梯度历史的二阶统计需要交叉项。设：

```text
m₊ = (mμ+mδ)/2,  m₋ = (mμ−mδ)/2
v₊ = (vμ+vδ+2c)/4
v₋ = (vμ+vδ−2c)/4,  c = EMA(gμ*gδ).
```

这是相同 EMA 权重下的原始矩变换。仅有 Adam 的两个对角二阶矩不能恢复 c：gμ=gδ 与 gμ=−gδ 可以给出相同的两个对角矩，却分别使 v₋ 或 v₊ 为零。遗漏交叉项，不能声称精确状态传递。

共有/差异模式若使用不同年龄，偏差修正与 EMA 有效权重还需独立处理；上式不自动解决不同年龄。完整方案必须明确：何时拆开 pair、一个子体再次分裂或被剪枝如何处理、如何保持有效步长、额外状态与孤立节点何时释放。

可研究保留分裂树、只增加新对比坐标的方式来避免频繁坐标合并，但会引入深度、剪枝、扫描和冗余坐标成本。这目前只是待解决选项，不是现成实现。不能用永不剪枝的浅层实验替代真实增密训练。

## 5. 成本和创新边界

相同叶子数量下，μ/δ 并不增加可渲染自由度。若每个成对标量再保存一个交叉二阶矩，成对 optimizer 的原始矩存储由 4 个标量增到 5 个；并非零额外显存。Python decode 若复制全场景参数，会带来 O(ND) 访存，不能只按被分裂的 K 个点估算。生产版本是否可只在 kernel 加载时 decode、以及该代价能否由减少迭代回收，均需实测。

必须对照 BOGausS 的 lifespan/继承、SteepGS 的 mean-shift/split 分解、已有层次 Gaussian 表示、multilevel/wavelet 参数化和自适应模型增长中的 optimizer-state transport。当前几组关键词搜索没有找到直接匹配，**这不是新颖性证明**。

下一步应先解决单次分裂的梯度/参数身份验证和强对照，再判断是否值得为重复拓扑状态转移设计更复杂的数据结构。没有任何已验证的 2× 或 SOTA 结论。
