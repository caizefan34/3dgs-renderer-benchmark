## 3. Phase A — event ordering (observed)

`update_learning_rate -> [oneup_sh_degree] -> render+loss -> backward ->
[update_max_radii2D, add_densification_stats] -> [densify_and_prune: clone ->
split -> prune] -> [reset_opacity] -> optimizer.step -> zero_grad`.

Topology and opacity reset run BEFORE the optimizer step; on topology
iterations the dense A_s step is a no-op (params just replaced with `grad=None`,
so `state["step"]` does not advance). LAVOS0 mirrors this ordering exactly.

## 4. Phase B/C — consumer trace + structural headroom

Per iteration the minimal exact-consumer set is
`C_t = nonzero_SH_grad_rows U topology-read-SH-rows U fence-rows`; pruned rows
discarded without SH observation are NOT consumers. Offline debt replay yields
`avoidable_transition_fraction`, `topology_forced_settle_fraction`, and the debt
length distribution (max/p50/p90/p99). Gates: H1 median avoidable `>= 0.40`,
H2 forced-settle `<= 0.25`, H3 p90 debt `>= 3`, H4 SH-Adam wall `>= 0.10`; and
`>= 2/3` scenes with avoidable `>= 0.55`.

## 5. Phase D — exact topology replay oracle

Both lanes (DENSE: step every row every iter; LAZY: defer zero-grad non-consumers,
settle only exact consumers + clone/split parents + fence rows, same baseline
topology) use the SAME per-row settlement primitive (isolated 1-row
`torch.optim.Adam(foreach=False)`), so deferral+replay is bitwise relative to
always-stepping. Fences materialize both lanes and compare SH theta / exp_avg /
exp_avg_sq / global step / Gaussian count by SHA256; any mismatch =>
`LAVOS0_TOPOLOGY_EXACTNESS_FAIL` (no tolerance rescue).

## 6. Phase E — performance oracle

`G_incremental = Delta_pre / (T_pre + T_post - existing_post15k_saving)`, using
the LOWER of the Amdahl/traffic estimate and the microbench-derived estimate.
Gates: early SH optimizer speedup `>= 1.35x` every scene, geomean `>= 1.50x`,
conservative full-30K reduction `>= 2%` in `>= 2/3` scenes, no regression
`> 0.5%`, topology/fence overhead `<= 25%` of gross savings. Strong headroom:
`>= 1.75x` every scene, `>= 3%` every scene, overhead `<= 15%`.
